# LRN-003 — pnpm `minimumReleaseAge` : quarantaine bloque `add` sur une dep transitive récente sans rapport

| Pattern observé                                                                                                             | Contexte                                                                                                                                                                                                                                                                                                                                  | Application future                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm add <pkg>` échoue avec `ERR_PNPM_NO_MATURE_MATCHING_VERSION` sur un paquet totalement étranger à celui qu'on installe | Politique globale `minimum-release-age=10080` (7j, `pnpm config get minimum-release-age`) bloquée par `@rollup/rollup-freebsd-arm64` (variante de plateforme optionnelle, publiée 4j avant), tirée en transitif par une re-résolution complète du lockfile déclenchée par le nouvel `add` — le paquet ciblé lui-même n'était pas en cause | Même mécanisme que `trustPolicy` (voir GLRN-234/GBDR-007 en mémoire globale) : débloquer ponctuellement avec `pnpm add <pkg> --config.minimum-release-age=0` plutôt que de modifier la politique globale ou d'exclure le paquet définitivement |
