# BDR-065 — README bilingue EN(canonique)/FR façon mini-LP, screenshots réels

**Décision** : `README.md` (anglais, canonique GitHub) + `README.fr.md` (français, lien de bascule en haut de chaque fichier), réécrits façon mini-LP avec captures réelles (6 animations Cubee, 4 skins alternatifs, 3 onglets Settings). Style aligné sur le skill `readme-writer` (badges `shieldcn`, table stack technique, footer signature "Made with ❤️").

**Pourquoi** : Repo destiné à être partagé publiquement (AGPL). Le README doit donner envie en attendant une vraie LP dédiée (`hooky.vercel.app`) — captures d'écran plutôt que placeholders, pour rendre le projet tangible.

**Alternatives considérées** : README mono-langue (anglais seul, convention habituelle de Baptiste) — écarté, demande explicite de version FR en plus.
