# LRN-036 — GDI screenshot ne capture pas fiablement les fenêtres transparentes WebView2

| Pattern observé                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                                                                                                                                           | Application future                                                                                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `System.Drawing.Graphics.CopyFromScreen` (PowerShell) ne montre jamais le contenu d'une fenêtre Tauri transparente/`alwaysOnTop`, alors que le backend confirme position correcte et `isVisible()=true` sans erreur. | Vérification automatisée de la bulle de notification Hooky (fenêtre `bubble`) : plusieurs cycles de debug via instrumentation (une commande custom écrivant l'état dans un fichier) ont confirmé que toute la chaîne applicative fonctionnait — seule la capture échouait. Confirmé a posteriori : Baptiste voyait la bulle normalement à l'écran. | Pour vérifier visuellement une fenêtre transparente à composition matérielle (WebView2/DirectComposition, Electron similaire), ne pas se fier à un screenshot GDI négatif comme preuve d'absence — demander confirmation directe à l'utilisateur, ou utiliser une capture qui gère la composition matérielle (Windows.Graphics.Capture API). |
