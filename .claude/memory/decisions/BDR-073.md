# BDR-073 — Refresh OAuth direct en HTTP plutôt qu'un subprocess `claude`

| Décision                                                                                                                                                                                                                                                                                                                                                                                                               | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                                                                                          | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `fetch_usage` (`src-tauri/src/lib.rs`) détecte un token expirant/expiré (`token_expiring_soon`, marge 5min) et appelle `refresh_oauth_token` : POST direct sur `https://platform.claude.com/v1/oauth/token` (`grant_type=refresh_token`, `client_id` public du CLI officiel), puis réécrit `.credentials.json` de façon atomique (fichier temp + rename), en ne touchant que `accessToken`/`refreshToken`/`expiresAt`. | Un utilisateur n'utilisant que l'app Desktop (jamais le CLI terminal) ne déclenche jamais le refresh natif du CLI -- le token reste périmé indéfiniment (cf. [BLK-033](../blockers/BLK-033.md)). `claude auth status`, testé en premier comme solution "discrète", s'est révélé NE PAS rafraîchir le token même sur un cas simulé expiré (cf. [LRN-083](../learnings/LRN-083.md)) -- seule une vraie session interactive le fait, en plusieurs secondes. | Spawn `claude auth status` en subprocess (implémenté puis retiré, testé inefficace) ; spawn une vraie session `claude` interactive (fonctionne mais coûte plusieurs secondes + usage réel à chaque refresh, écarté par Baptiste comme trop lent). | actif  |
