# BDR-104 — Menu clic droit : fenêtre Tauri dédiée + DropdownMenu shadcn

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Pourquoi                                                                                                                                                                                                                                                             | Alternatives considérées                                                                                                                                                                                   | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le clic droit sur le pet spawn une fenêtre Tauri « menu » (transparente, sans décoration, `alwaysOnTop`, `skipTaskbar`) posée au curseur, qui affiche un `DropdownMenu` shadcn/ui (Paramètres, Quitter — mêmes entrées que le tray). Coin du menu sur le curseur, retourné à gauche/en haut si le bord de la zone utile (`workArea`) le couperait. Dimensions fixes (`CONTEXT_MENU_*` dans `layout.ts`) pour positionner sans mesurer. « Quitter » passe par une commande Rust `quit_app`, « Paramètres » relaie l'event `hooky-open-settings` déjà écouté par « main ». | La fenêtre « main » ne fait que la taille de l'avatar plus `AVATAR_SHADOW_GAP` : un menu rendu dedans serait rogné par le bord de la fenêtre. Même mécanique que la bulle de notification (fenêtre dédiée). Baptiste demandait explicitement un composant shadcn/ui. | Menu natif Tauri (`Menu.popup`) : écarté, pas du shadcn. Menu dans « main » : rogné. Agrandir « main » pendant le menu : décale l'avatar, risque de flash (cf. mémoire projet sur les redimensionnements). | actif  |
