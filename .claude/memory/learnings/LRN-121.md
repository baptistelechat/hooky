# LRN-121 — Spawn de fenêtre Tauri sans verrou = crash WebView2 possible

| Pattern observé                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                                                                         | Application future                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `WebviewWindow.getByLabel(label).close()` suivi de `new WebviewWindow(label, ...)` peut crasher WebView2 nativement (`null pointer dereference`, non rattrapable côté JS) si la fonction est rappelée avant que le cycle close+create précédent soit terminé, même si chaque appel isolé est correct. | `spawnContextMenuWindow` (clic droit sur le pet) n'avait aucun garde de ce genre, contrairement à `useBubbleWindow` qui documentait déjà ce risque — mais uniquement pour le double-effet React StrictMode, pas pour une répétition venant de l'utilisateur (clic droit rapide). | Pour tout futur spawn de fenêtre Tauri déclenché par une action répétable côté utilisateur, poser un verrou de module (flag bool + try/finally) avant le premier `close()`/`new WebviewWindow`, même si la fonction paraît déjà idempotente via `getByLabel`. |
