# BDR-096 — Options d'installateur : FR+EN, licence AGPL, métadonnées

| Décision                                                                                                                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                                                                                                                                                    | Alternatives considérées                                                                                                                                                                                                                                                                                                                                       | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Dans `tauri.conf.json` : `languages: ["French", "English"]` avec `displayLanguageSelector`, `licenseFile: "../LICENSE"` (page « J'accepte » AGPL-3.0), `publisher: "Baptiste LECHAT"`, `shortDescription` (« A tiny desktop pet that reacts in real time to Claude Code hooks. »), `homepage`, `copyright`. `Cargo.toml` : même description, `authors = ["Baptiste LECHAT"]`. `installMode` reste `currentUser`. | Le projet est destiné à être partagé publiquement : un installateur bilingue, un éditeur lisible dans Windows et l'AGPL visible avant installation sont les défauts qui se voient. `currentUser` est imposé par le hook `SessionStart`, qui lit `HKCU\...\Uninstall\Hooky`. | `perMachine` / `both` (écartés : écrivent dans `HKLM`, casseraient BDR-079). Template `.nsi` custom (trop lourd). Signature du code (certificat payant, à revoir pour une diffusion large). `installerHooks` pour retirer le hook `SessionStart` à la désinstallation (écarté : modifier du JSON depuis NSIS). `startMenuFolder` (inutile avec une seule app). | actif  |
