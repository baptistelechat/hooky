# LRN-029 — Spread avec clé explicitement `undefined` écrase une valeur du côté cible

| Pattern observé                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{ ...base, ...override }` où `override` porte une clé explicitement à `undefined` (ex. `{ body: "#fff", eyes: undefined }`) écrase la valeur existante de `base` par `undefined` -- même si l'intention était de ne modifier que `body`. Le spread ne fait aucune distinction entre "clé absente" et "clé présente valant undefined". | `getAvatarBundle` mergeait `colors` avec un override construit avec les deux clés toujours présentes (`{ body: overrideBody, eyes: overrideEyes }`). Éditer une seule des deux couleurs laissait l'autre à `undefined`, cassant la validation du schéma runtime (`colors.eyes` requis en string) -- `createAvatar` throw synchrone sans error boundary, fenêtre transparente vide (cf. [ZBLK-016](../archive/blockers/ZBLK-016.md)). | Ne jamais construire un objet d'override avec des clés systématiquement présentes si leur valeur peut être `undefined`. Filtrer les clés définies avant le spread, ou merger champ par champ avec un test explicite (`if (value) target.x = value`). |
