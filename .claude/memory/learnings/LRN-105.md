# LRN-105 — `shadcn add` tiers : `registryDependencies` non namespacé échoue

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                         | Application future                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `npx shadcn add https://shadercn.run/r/orb-01.json` échoue : sa `registryDependencies: ["orb"]` n'est pas namespacée, la CLI la cherche sur `ui.shadcn.com/r/styles/base-nova/orb.json` (introuvable). Les fichiers du JSON sont aussi préfixés `registry/` (`registry/components/orbs/orb-01/...`) alors que `target` vise `components/...`. Sans `www.`, `shadercn.run` redirige (`curl` renvoie « Redirecting... ») : utiliser `curl -L` et `www.shadercn.run`. | Installation des orbs shadercn dans Hooky (`components.json` style `base-nova`). | Installer d'abord la dépendance en URL complète (`.../r/orb.json`), puis, si la CLI échoue encore, télécharger le JSON avec `curl -sL`, écrire chaque `files[].content` sous `src/` (préfixe `registry/` retiré) et ajouter à la main `dependencies` (`vgpu`, `typegpu`). Vérifier ensuite les alias `@/` et `pnpm typecheck`. |
