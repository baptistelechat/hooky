# LRN-037 — Tauri `monitorFromPoint` vs `currentMonitor`

| Pattern observé                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                | Application future                                                                                                                                                    |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `currentMonitor()` (import `@tauri-apps/api/window`) est une fonction libre qui renvoie toujours le moniteur de LA FENÊTRE QUI L'APPELLE, pas une méthode disponible sur une instance `WebviewWindow` ciblée (`mainWindow.currentMonitor()` n'existe pas côté types). | Positionnement de la bulle de notification Hooky au-dessus/en-dessous du pet, calculé depuis la fenêtre `bubble` mais basé sur la position réelle de la fenêtre `main`. | Pour connaître le moniteur d'UNE AUTRE fenêtre Tauri (pas la sienne), utiliser `monitorFromPoint(x, y)` avec un point de cette fenêtre plutôt que `currentMonitor()`. |
