# LRN-096 — Tester du front sans navigateur : esbuild + stubs DOM

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                                                                                | Application future                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tester un module front qui touche le DOM (canvas, `Image`) sans navigateur : bundler le vrai fichier avec le binaire esbuild du store pnpm (`node_modules/.pnpm/@esbuild+win32-x64@<version>/node_modules/@esbuild/win32-x64/esbuild.exe`, non exposé comme commande) en `--platform=node --format=cjs`, neutraliser `import.meta.glob` par `--define:import.meta.glob=__glob --banner:js='globalThis.__glob=()=>({})'`, puis l'exécuter avec un faux `Image` et un faux `document.createElement('canvas')` dont `getImageData` renvoie de vrais pixels exportés en binaire par Pillow. | Le navigateur intégré refusait les origines locales ([BLK-034](../blockers/BLK-034.md)) : impossible d'exécuter `spriteColor.ts` dans un navigateur. Le harnais Node a validé toute la logique réelle (teintes, seuils, contraste) sur les pixels de `work-blue-cat` : `#57a072`. | Cela teste la logique, pas le rééchantillonnage du navigateur (le canvas est simulé) : à compléter par un test dans l'app. Un portage Python de l'algorithme donne une prédiction rapide, mais teste un portage, pas le code livré. |
