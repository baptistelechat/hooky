# LRN-042 — React StrictMode + effet async (`listen()`) = fenêtre de course avec deux abonnements réels simultanés

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `React.StrictMode` double-invoque le setup d'un effet (mount → cleanup → remount) de façon synchrone — mais si le setup lance une opération ASYNCHRONE dont le cleanup dépend (ex: `listen()` de Tauri, résolvant une promesse plus tard), le cleanup de la 1re invocation ne peut désabonner qu'après résolution de SA PROPRE promesse. Ça laisse une brève fenêtre où DEUX abonnements réels sont simultanément actifs. Un event externe arrivant dans cette fenêtre est livré deux fois côté JS pour une seule émission réelle. | `useHookyState` (Hooky) écoutait un event Tauri via ce pattern. Un seul event backend était reçu deux fois côté JS ; avec un compteur local (`prev.revision + 1`) ça produisait deux valeurs DIFFÉRENTES (deux rendus, donc deux effets applicatifs — son + bulle — pour un seul event réel). | Pour un effet qui s'abonne à une source externe de façon asynchrone, ne pas se fier à un compteur local incrémenté à chaque livraison (vulnérable à une double-livraison StrictMode). Utiliser un identifiant fourni par la SOURCE elle-même (ex: numéro de séquence serveur) et dédupliquer dessus — dans un `setState` fonctionnel, retourner `prev` inchangé si l'identifiant a déjà été vu, pour que React bail out sans re-render. |
