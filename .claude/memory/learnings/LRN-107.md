# LRN-107 — Retrait manuel : prouver l'équivalence par git diff --stat

| Pattern observé                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                                                                                                                                                                  | Application future                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Après avoir retiré une fonctionnalité à la main (au lieu d'un `git revert`), `git diff <commit-avant-la-feature> --stat -- <chemins>` doit être **vide** : c'est la preuve que rien n'a été oublié ni ajouté. Une sortie = du bruit. | Retrait du spike orbs sur Hooky : `git diff 884a9d2 --stat` a d'abord montré deux fichiers de bruit, `Avatar.tsx` (le hook formateur post-Edit avait recompacté un import et ajouté une ligne vide) et `vite.config.js` (fichier généré, cf. [LRN-108](../learnings/LRN-108.md)). `rm -rf` sur le dossier a été refusé ; `git rm -r` est passé et reste récupérable dans l'historique. | Trouver le commit d'avant la feature (`git log`), lancer le diff **après** lint et build (ils régénèrent des fichiers), lire chaque fichier restant, puis restaurer le bruit à l'identique : `git checkout <commit-avant> -- <fichier>` suivi de `git reset -q <fichier>` pour ne pas le laisser stagé. Répéter jusqu'à sortie vide. Pour supprimer un dossier suivi, préférer `git rm -r` à `rm -rf`. Après un Edit, se méfier du hook formateur : relire le diff plutôt que supposer que l'édition est neutre. |
