# LRN-043 — Tauri `setIgnoreCursorEvents` non fiable sur Windows/WebView2

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Contexte                                                                                                                                                                                                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getCurrentWindow().setIgnoreCursorEvents(true)` (ou l'équivalent Rust `window.set_ignore_cursor_events()`) ne laisse pas fiablement les clics traverser vers l'application derrière sous Windows/WebView2 — même avec une implémentation complète et correcte (toggle dynamique sur `mousemove`, thread de polling `AppHandle::cursor_position()` côté Rust pour contourner le fait que la fenêtre cesse de recevoir des events une fois en mode "ignore"). Bug amont connu et non résolu : [tauri-apps/tauri#11461](https://github.com/tauri-apps/tauri/issues/11461) (fermé "not planned"). | Tentative de laisser les zones transparentes d'une fenêtre Hooky (avatar + bulle) cliquables pour l'application derrière. Implémentation complète (commande Rust `set_click_through` + thread de sondage curseur + hook JS `useClickThrough`) confirmée non fonctionnelle par test utilisateur direct ("le clic ne traverse pas"), retirée intégralement plutôt que de garder du code mort. | Sur Windows/WebView2, ne pas investir dans une implémentation de click-through dynamique basée sur `setIgnoreCursorEvents` sans un test de faisabilité minimal au préalable — vérifier d'abord les issues GitHub `tauri-apps/tauri` pour ce mécanisme sur la plateforme cible avant d'y consacrer du temps d'implémentation. |
