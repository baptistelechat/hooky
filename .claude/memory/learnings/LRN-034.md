# LRN-034 — Bash tool : `run_in_background:true` + `&` en fin de commande = process zombie

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                         | Application future                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_in_background:true` bascule déjà toute la commande en arrière-plan côté outil. Ajouter en plus un `&` à la fin de la commande (pour backgrounder un sous-process dans le script) fait sortir immédiatement le wrapper shell avec le code 0, sans attendre le process réel -- qui continue de tourner en orphelin/zombie, invisible pour le suivi de tâche de l'outil, mais gardant ses ressources (ex. port réseau) ouvertes. | `rtk pnpm tauri dev &` lancé avec `run_in_background:true` : la commande "réussissait" immédiatement (exit 0, aucun serveur réellement surveillé), laissant un process `node` zombie sur le port 1420. La tentative suivante de `tauri dev` échouait avec "Port 1420 is already in use" (cf. [BLK-019](../blockers/BLK-019.md)). | Ne jamais combiner `run_in_background:true` avec un `&` en fin de commande -- l'outil gère déjà le backgrounding. Si un process zombie est suspecté après un lancement qui "a réussi trop vite", vérifier le port concerné (`Get-NetTCPConnection -LocalPort <port>` sous Windows) avant de relancer. |
