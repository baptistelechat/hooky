# BDR-109 — Dots perso : planche en IndexedDB, index en localStorage

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Pourquoi                                                                                                                                                                                                                                         | Alternatives considérées                                                                                                                                                                         | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Un personnage Dots Lab importé par l'utilisateur a pour id `dots:custom:<uuid>`. Sa planche est stockée dans IndexedDB (base `hooky-dots`, store `sheets`), et seul un index `id -> { name }` vit en localStorage (clé et event Tauri `hooky-custom-dots`, même contrat que les avatars custom). Le bundle garde la forme d'une planche du repo grâce à une pseudo-URL `hooky-dots-sheet:<id>`, résolue par `loadDotsSheetText` (`src/lib/customDots.ts`) ; `getAvatarBundle` reçoit l'index en 5e paramètre. | Une planche pèse 0,5 à 0,9 Mo : cinq ou six satureraient le quota du localStorage, et chaque écriture rediffuserait le tout par IPC. IndexedDB est partagé par les fenêtres pet et settings (même origine) sans capability Tauri supplémentaire. | Tout en localStorage comme les avatars custom (écarté : quota). Écriture sur disque par une commande Rust, comme les pets Codex (écarté : plus de code et une capability pour le même résultat). | actif  |

## Notes

- Conséquence : ces personnages ne sont pas dans l'export de configuration, comme les avatars custom.
- Stockage vérifié dans un navigateur (enregistrement, relecture identique, découpage, suppression) ; Baptiste a confirmé que l'import fonctionne dans l'app.
