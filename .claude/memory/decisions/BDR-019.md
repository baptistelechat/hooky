# BDR-019 — CORS permissif sur le serveur axum local

**Décision** : `tower_http::cors::CorsLayer::permissive()` ajouté à la route `/event` du serveur axum (`src-tauri/src/lib.rs`).

**Pourquoi** : La fenêtre settings (onglet Animation, clic sur une carte pour tester en live) appelle `/event` via `fetch()` depuis son propre webview -- une requête cross-origin bloquée sans ces headers, contrairement aux vrais hooks Claude Code qui posent en `curl` (pas de préflight CORS navigateur pour ce trafic-là). Serveur bindé sur `127.0.0.1` uniquement -- pas de risque à autoriser toute origine ici.

**Alternatives considérées** : CORS scopé à une origine précise (rejeté : l'origine exacte du webview Tauri en dev/prod n'est pas triviale à connaître à l'avance, `127.0.0.1` non exposé de toute façon)
