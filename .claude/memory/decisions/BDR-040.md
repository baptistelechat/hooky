# BDR-040 — Drag restreint via `data-drag-handle` + `closest()`, révise BDR-038

| Décision                                                                                                                                                                                                                                                                                                                                 | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Alternatives considérées                                                                                                                                                                                                                                                                     | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le handler `mousedown` sur le wrapper racine (drag de fenêtre) ignore désormais les clics dont la cible ne descend pas d'un élément marqué `data-drag-handle` (box de l'avatar, bulle de notification visible, badge d'icône Lucide de `AnimationOverlay`) — `pointer-events` reste inchangé partout, aucune tentative de click-through. | Retour utilisateur direct (capture d'écran) : la fenêtre 300×330 (élargie pour la bulle, cf. [BDR-037](BDR-037.md)) laisse un bandeau vide de 90px au-dessus de l'avatar quand la bulle n'affiche rien, et des marges gauche/droite autour d'un avatar réduit — tout ce vide restait draggable. Ce n'est PAS la même tentative que [BDR-038](BDR-038.md) : celle-ci visait un click-through vers l'app derrière (jamais fonctionnel sur Windows/WebView2, cf. [LRN-043](../learnings/LRN-043.md)) via `pointer-events`. Ici l'objectif est seulement d'ignorer le mousedown sur du vide — un hit-test JS (`e.target.closest()`) sur l'event lui-même n'a aucun des écueils qui ont fait échouer BDR-038 (pas de risque d'hériter `pointer-events:none` dans le SVG, cf. [LRN-041](../learnings/LRN-041.md), pas de dépendance à `setIgnoreCursorEvents`). | Réduire la largeur de fenêtre/bulle pour matcher `avatarSize` — corrigerait le symptôme visuel mais pas le vrai bug (zone morte draguable) ; laissé en question ouverte pour Baptiste. Reprendre l'approche `pointer-events` de BDR-038 — écartée, même classe de fragilité déjà documentée. | actif  |
