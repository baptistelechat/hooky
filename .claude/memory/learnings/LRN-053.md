# LRN-053 — `startDragging()` (Tauri) résout sa promesse au lancement du drag, pas à la fin

| Pattern observé                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                                           | Application future                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getCurrentWindow().startDragging()` retourne une promesse qui se résout dès que le drag natif DÉMARRE, pas quand il se termine (`mouseup`). Chaîner du code après `.then()` en pensant "drag terminé" s'exécute en réalité au tout début du drag. | Tentative de corriger la position de la fenêtre juste après un drag (`startDragging().then(() => snapWindowToScreen())`) -- ne corrigeait jamais rien, le code s'exécutait immédiatement, avant même que l'utilisateur ait commencé à bouger la souris. Confirmé par recherche externe : issue GitHub tauri-apps/tauri#4825, fermée "not planned". | Pour toute action devant se déclencher à la FIN d'un drag Tauri, ne jamais se fier à `.then()` sur `startDragging()` -- soit abandonner `startDragging()` au profit d'un drag manuel (`mousemove`/`mouseup` globaux + `setPosition()`, cf. [BDR-044](../decisions/BDR-044.md)), soit poser un listener `mouseup` explicite en parallèle. |
