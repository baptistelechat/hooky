# BDR-069 — Icônes UsagePanel ciblées kind/modèle exact, pas de table par modèle

| Décision                                                                                                                                                                                                | Pourquoi                                                                                                                                                                                                                                                                                                | Alternatives considérées                                                                                                                                       | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Icône `Clock` (lucide-react) pour le kind "session", `Sparkles` (lucide-react, statique) pour le modèle exact "Fable" via `modelName` — pas de table de correspondance icône par modèle pour les autres | Le glyphe texte fixe précédent ("5h", initiale de modèle) créait une ambiguïté : Baptiste a cru que "5h" ne se mettait pas à jour, alors que c'est un label de catégorie fixe par design, pas une valeur mesurée. Une table complète serait une abstraction pour des modèles hypothétiques non demandés | `BookOpen` pour Fable (proposé, rejeté par Baptiste au profit de `Sparkles`) ; garder le glyphe texte pour "session" (rejeté, source de la confusion initiale) | actif  |
