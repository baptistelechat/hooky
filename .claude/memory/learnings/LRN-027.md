# LRN-027 — Calculer la durée réelle du cycle d'animation plutôt qu'un timeout arbitraire

| Pattern observé                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                                                                                                         | Application future                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour désynchroniser N previews live d'un même moteur d'animation (chacune joue sa propre animation en boucle indépendamment), calculer la durée exacte d'un cycle depuis les données déclarées de l'animation (`steps[].holdMs + transitionMs`) plutôt qu'un délai arbitraire, puis repick au hasard (en excluant l'animation courante) quand ce cycle se termine. | `AvatarPicker.tsx` : chaque carte du picker (une par avatar) jouait initialement "idle" pour toutes — synchronisées, effet robotique. Baptiste a explicitement rejeté une première tentative avec une liste curatée d'animations "accueil" + `setTimeout` de durée fixe, en demandant de piocher dans les 23 animations réelles et de relancer un pick aléatoire exactement quand le cycle précédent se termine. | Toute grille de previews animées en boucle (ex. futures grilles de validation) : dériver la durée du timer depuis les données réelles de l'animation plutôt qu'une constante devinée — évite de couper une pose à mi-chemin et rend le résultat correct par construction plutôt que par ajustement empirique. |
