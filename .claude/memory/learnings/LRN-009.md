# LRN-009 — Vérifier par fetch direct les affirmations chiffrées d'un agent de recherche

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                          | Application future                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un agent de recherche (`claude-code-guide`) a livré une réponse globalement correcte (liste de 12 valeurs `notification_type`, confirmée ensuite par fetch direct de `hooks.md`) mais y a ajouté des détails non vérifiés et non corroborés (contraintes de version type "v2.1.198+"/"v2.1.234+" absentes du fetch direct de la même page) — plausibles, potentiellement fabriqués | Deux occurrences dans la même session : une fois pour confirmer une restriction Claude Code (issue GitHub citée, vérifiée exacte par fetch direct), une fois pour une liste de valeurs avec contraintes de version (partiellement non vérifiable) | Toute affirmation d'un agent de recherche portant un numéro précis (version, issue GitHub, date) et destinée à guider une décision ou être répercutée à l'utilisateur doit être re-vérifiée par une source primaire directe (fetch de la doc/issue elle-même) avant d'être présentée comme un fait établi — surtout quand le niveau de détail dépasse ce que la question posée exigeait |
