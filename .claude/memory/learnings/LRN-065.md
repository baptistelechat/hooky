# LRN-065 — Redimensionner une fenêtre AVANT `show()` élimine le flash de resize d'une fenêtre à contenu variable

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Application future                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Redimensionner/repositionner une fenêtre déjà VISIBLE produit un flash perceptible (deux appels IPC non parfaitement atomiques, webview qui doit re-layouter une surface déjà peinte). La MÊME opération sur une fenêtre créée `visible: false` n'a strictement aucun coût visuel, puisque rien n'est encore montré à l'écran : peindre le contenu réel une première fois pour le mesurer (`getBoundingClientRect()`), `setSize()`+`setPosition()`, PUIS `show()` -- élimine du même coup la tension habituelle d'une fenêtre à taille fixe devinée (trop petite = troncature, trop grande = espace mort visible). | Fenêtre bulle de notification Hooky, contenu (message texte) de longueur variable et inconnue à l'avance : plusieurs tentatives de hauteur fixe (70px, 80px) tronquaient les messages longs ou laissaient un vide pour les messages courts. Le resize-avant-show règle les deux simultanément, contrairement à un resize d'une fenêtre déjà affichée -- classe de bug déjà abandonnée plus tôt sur ce même projet pour cause de flash (cf. [ZBDR-052](../archive/decisions/ZBDR-052.md)). | Pour toute fenêtre popup/tooltip Tauri à contenu de taille variable non connue à la création, préférer create(`visible:false`) → mesure DOM du rendu réel → resize/reposition → `show()`, plutôt qu'une taille fixe devinée ou un resize d'une fenêtre déjà visible. |
