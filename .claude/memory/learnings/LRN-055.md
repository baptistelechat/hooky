# LRN-055 — Un clamp de drag doit border le bord RÉEL du contenu, pas la boîte englobante

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                             | Contexte                                                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Si une boîte englobante (ex. une fenêtre) contient un élément plus petit qu'elle avec une marge variable, clamper le DRAG sur les bords de la boîte englobante (pas ceux de l'élément réel) désynchronise le curseur de l'objet visuellement déplacé : le bord "lointain" (dans la marge, souvent invisible) touche l'écran avant que l'élément réel n'atteigne lui-même l'écran, et le curseur continue de bouger sans plus rien déplacer. | Fenêtre Hooky (avatar + bulle) -- clamp vertical basé sur toute la hauteur de fenêtre au lieu du bord réel de l'avatar (qui varie avec `avatarSize` et le flip). Symétrique au clamp horizontal, déjà correct depuis le début. | Pour tout clamp de drag sur un conteneur à taille fixe contenant un élément à taille/position variable, calculer la marge à partir du bord RÉEL de l'élément visible, jamais de la boîte englobante entière -- surtout si cette boîte réserve un espace asymétrique (zone vide d'un seul côté). |
