# LRN-081 — Relancer une app desktop complète pour tester perturbe l'écran réel de l'utilisateur

| Pattern observé                                                                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                                                                         | Application future                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour valider un fix backend (`fetch_usage`/backoff), plusieurs relances du binaire Tauri complet (avec fenêtre webview visible) ont perturbé le bureau de Baptiste en pleine session -- une fois avec une page d'erreur de dev server, une fois avec un process mort sans le savoir. | Le vrai test utile (valider la formule de backoff) a fini par se faire via un `#[cfg(test)]` déterministe (fonction pure `usage_backoff_delay`, zéro réseau, zéro fenêtre) plutôt qu'en attendant un succès réel contre un rate-limit externe imprévisible (potentiellement 1h). | Dès qu'un test de code backend risque d'ouvrir une fenêtre/UI visible pour l'utilisateur, isoler la logique testée en fonction pure testable en unitaire avant de recourir à un relaunch complet de l'app. |
