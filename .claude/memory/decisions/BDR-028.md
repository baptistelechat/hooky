# BDR-028 — Registre multi-avatar auto-découvert via `import.meta.glob`

| Décision                                                                                                                                                                                                                                           | Pourquoi                                                                                                                                                                                                                                                                           | Alternatives considérées                                                                                                                                                                                                     | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Les avatars vivent dans `src/components/avatars/*.json` ; `avatarDefinition.ts` les charge tous via `import.meta.glob("./avatars/*.json", { eager: true })` et construit un `avatarRegistry` (id → bundle) une seule fois au chargement du module. | Baptiste voulait donner plusieurs exports du Studio bible-strong et pouvoir en sélectionner un, persisté. Déposer un fichier dans le dossier doit suffire à le faire apparaître dans le picker — zéro changement de code pour ajouter un avatar, y compris pour Baptiste lui-même. | Liste manuelle d'imports statiques par avatar (rejeté : un ajout = une PR) ; chargement dynamique lazy (`eager: false`, rejeté : peu de fichiers, JSON léger, la latence d'un `import()` par avatar au clic n'apporte rien). | actif  |
