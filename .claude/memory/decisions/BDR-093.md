# BDR-093 — Spike orbs poussé malgré licence NC, distribution à trancher

**Décision** : Le spike orb (shadercn, WebGPU) est committé et poussé sur `development` (`9fde588`, gitmoji 🚧 WIP) **avec** les fichiers `src/components/orbs/`, dont les shaders sont tous sous licence « non-commercial use only » (XorDev). La façon de distribuer les orbs reste à trancher en Étape 14.

**Pourquoi** : Baptiste juge le risque faible (projet perso, partage limité, attribution conservée dans l'en-tête des fichiers) et voulait tout versionner. Le rendu, la transparence et le coût GPU sont validés (~0,6 % sur RTX, orb 170 px). Le risque réel : un repo public sous AGPL offre à tous un droit d'usage commercial que XorDev n'a accordé qu'à shadercn.

**Alternatives considérées** : (A) demander l'accord de XorDev pour redistribuer sous AGPL ; (B) garder le runtime MIT (`renderer.ts`, `canvas.tsx`) et écrire des shaders maison sous licence libre ; (C) ne pas livrer les orbs, l'utilisateur les installe (`.gitignore`), même principe que les pets Codex. Recommandation donnée : ne pas pousser tant que ce n'est pas tranché (C, ou B éventuellement après A).
