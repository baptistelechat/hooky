# LRN-124 — Animer un sprite dans un mod : Svg + SMIL discret

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| L'élément `Svg` d'un mod accepte une `<image href="data:image/png;base64,...">` animée par `<animate attributeName="x" calcMode="discrete" keyTimes=...>` : le défilement d'une bande de frames fonctionne dans l'app desktop (pas de script). Limites : 131 072 caractères par SVG (réduire la taille des frames 64, 48, 40, 32 px jusqu'à passer), `values` et `keyTimes` de même longueur sans valeur de bouclage en plus, `Client` limité à 1 appel/s et sans `Svg` | Pet animé de `hooky-pet` (pets Codex découpés par ligne, avatars procéduraux rastérisés) | Pour animer un visuel dans un mod : pré-rendre une bande de frames PNG, un SVG par animation, durées variables via `keyTimes`. Un `Pane` accepte le même SVG |
