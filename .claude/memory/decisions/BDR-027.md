# BDR-027 — Résolution d'état à deux niveaux (priorité intra-session, récence inter-sessions)

| Décision                                                                                                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                              | Alternatives considérées                                                                                                                                                                                                                                   | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `resolve_state` groupe désormais les entrées par `session_id`. Au sein d'un groupe (parent + ses sous-agents), `STATE_PRIORITY` choisit l'état représentant. Entre groupes (sessions différentes), c'est la session dont `last_event_at` est le plus récent qui gagne, pas la priorité globale | Une priorité statique unique pour arbitrer entre sessions différentes masquait une session qui démarre activement (ex. `SessionStart` → `listening`) derrière un état "au repos" (`celebrate`/`idle`/`bored`) d'une AUTRE session récemment terminée, uniquement parce qu'il était plus haut dans `STATE_PRIORITY` — bug générique (pas propre à `celebrate`), rapporté par Baptiste à plusieurs reprises en usage réel multi-session | Simplement réordonner `STATE_PRIORITY` (`celebrate` sous `thinking`/`listening`) — rejeté par Baptiste : ne règle que le symptôme observé, pas le principe (n'importe quel autre état "au repos" continuerait à masquer un état actif d'une autre session) | actif  |

Validé en live par tests curl isolés reproduisant les deux scénarios : `Stop`(sessA)→`celebrate` puis `SessionStart`(sessB) → résolu `listening` (sessB gagne) ; `Stop`(sessC)→`celebrate` puis `SubagentStop`(sessC/ghost) → résolu `celebrate` (protection intra-session intacte).
