# BDR-095 — Bandeaux d'installateur commités, générés à la main

| Décision                                                                                                                                                                                                                                                                                     | Pourquoi                                                                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                                                                                                                                        | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `sidebar.bmp` et `header.bmp` (dans `src-tauri/installer/`) sont commités. `gen-images.ps1` les régénère depuis `icons/icon.png`, mais c'est un outil manuel : la CI (`release.yml`) ne le lance jamais. Le bandeau affiche le logo, « Hooky » et `for Claude Code`, sans numéro de version. | C'est GitHub Actions qui produit le `.exe`, et Baptiste ne veut pas d'une étape PowerShell de plus dans la release. Sans version dans l'image, plus rien à régénérer à chaque `pnpm release:*`. « for Claude Code » est neutre en langue, alors que le bandeau est une image fixe et l'installateur bilingue. | Version lue dans `tauri.conf.json` par le script (écartée : à relancer avant chaque release). « Le compagnon de Claude Code » puis « Ne voit jamais ton code » (écartés : français figé dans une image bilingue). Générer les BMP dans la CI (écarté : complexité pour une image qui ne change presque jamais). | actif  |
