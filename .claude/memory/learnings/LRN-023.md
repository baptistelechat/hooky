# LRN-023 — Claude Code hooks : `session_id` partagé entre parent et sous-agents, seul `agent_id`/`agent_type` distingue

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                                                                                                                                                                                                                                      | Application future                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La doc officielle Claude Code hooks confirme : "All hook inputs share `session_id`, `cwd`, and `hook_event_name`. `agent_id` and `agent_type` are populated when the hook fires inside a subagent." Un sous-agent — qu'il soit lancé explicitement (tool `Agent`/`Task`) ou automatiquement par le harness (fork système : consolidation mémoire, résumé, suggestion) — porte donc le MÊME `session_id` que sa session parente, seul `agent_id` change | Rencontré en debuggant Hooky (le serveur local recevant les hooks) : un `SubagentStop` tardif écrasait l'état `Stop` de sa propre session parente, faute de distinguer les deux via `agent_id`. Confirmé empiriquement par un test direct (payload loggé) : `agent_id` présent, `agent_type` vide (`""`) pour un fork système invisible, vs un vrai type nommé (`general-purpose`, `Explore`...) pour un sous-agent explicite | Toute intégration consommant les hooks Claude Code et suivant un état "par session" doit traiter `session_id` comme non-unique par conversation visible : grouper/filtrer par `agent_id` pour distinguer le parent de ses sous-agents (visibles ou forks automatiques invisibles), sous peine qu'un sous-agent écrase silencieusement l'état de son parent |
