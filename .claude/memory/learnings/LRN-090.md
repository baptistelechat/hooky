# LRN-090 — Config partagée : résoudre les chemins à l'exécution

**Pattern observé** : Un fichier de config partagé ou synchronisé entre plusieurs postes (dotfiles, `~/.claude/settings.json`) ne doit contenir aucun chemin écrit à l'installation pour une seule machine : chaque poste écraserait la valeur de l'autre. Le chemin se résout à l'exécution (registre, variable d'environnement, `which`).

**Contexte** : `install_claude_hooks` aurait pu substituer `std::env::current_exe()` dans le snippet, mais le `settings.json` est partagé entre deux postes aux dossiers d'installation différents (C: / D:).

**Application future** : Avant de substituer un chemin dans une config à l'installation, se demander si ce fichier est partagé ou synchronisé. Si oui, préférer une commande qui retrouve le chemin à l'exécution, et garder la même ligne pour tous les postes.
