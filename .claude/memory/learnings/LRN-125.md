# LRN-125 — Lien Dots Lab : `m1` + 8 index base 36 + couleur

| Pattern observé                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                 | Application future                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le fragment d'un lien Dots Lab (`#m1010077f0161618`) se lit : `m1`, puis 8 caractères en base 36 (forme, yeux, sourcils, encre, taille, écart, inclinaison, état), puis la couleur en hexa. La bouche n'est pas dans le lien. Les presets du site sont le tableau `FAMILIES` de la page (3 familles, 19 personnages). | Ajout des 7 presets manquants : les 7 liens étaient tous des ronds (forme `0`), différenciés par les yeux et la couleur. | Pour nommer ou vérifier un personnage sans ouvrir le site, décoder le lien. Convention de nom retenue quand plusieurs planches partagent une forme : `<forme>-<yeux>` (`round-pills`, `round-rings`...), avec un suffixe si le couple se répète (`round-rings-small`). |
