# LRN-014 — `getBBox()` sur un SVG tiers non maîtrisé peut capter des éléments invisibles

| Pattern observé                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mesurer la vraie boîte englobante du SVG rendu (`svg.getBBox()`) pour calculer un scale-to-fit a fait rétrécir un avatar (Cubee) qui n'avait pourtant aucun élément débordant -- probable élément non visible (hit-area, etc.) inclus dans le calcul du moteur tiers, impossible à distinguer sans connaître sa structure DOM interne exacte. | `useAvatarFitScale` (hook basé `getBBox()`) introduit pour corriger le crop de l'avatar "Sunee" (satellites positionnés hors du corps principal) -- a introduit une régression sur les avatars sans satellites, remontée par retour utilisateur avec capture d'écran. | Face à un besoin de mesure géométrique sur le rendu d'une librairie tierce dont on ne maîtrise pas la structure DOM interne, préférer un calcul statique depuis les données déclaratives qui pilotent ce rendu (ici `avatar.json`) plutôt qu'une mesure DOM runtime -- plus prévisible, ne dépend pas de détails d'implémentation non documentés. |
