# BDR-032 — Variante `responsive` (cva) sur Button plutôt que className dupliqué

**Décision** : Ajout d'une variante booléenne `responsive` (cva) dans `src/components/ui/button.tsx`, encapsulant `w-full @md/field-group:w-auto`. Remplace le `className` identique dupliqué 5 fois (`ConfigurationField` ×3, `AvatarPicker` ×2).

**Pourquoi** : Baptiste a explicitement demandé de gérer ça au niveau du composant Button plutôt qu'en `className` custom -- règle déjà établie du projet (`shadcn_unicity.md` : une variante visuelle réutilisable va dans `cva()`, pas répétée en `className` à chaque call site, cf. code_smells.md "3+ copies → refactor").

**Alternatives considérées** : Garder le `className="w-full @md/field-group:w-auto"` répété par call site (rejeté explicitement par Baptiste).
