# BDR-078 — Pets Codex : choix UX tranchés (sleeping, effets, drag, rendu)

| Décision                                                                                                                                                                                                                                                                                                                                      | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                   | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Pour les pets Codex : **`sleeping`** = ligne `idle` ralentie + atténuée + badge Zzz ; **effets ponctuels** (confettis, bounce, shake) conservés ; **`run-left`/`run-right`** joués selon la direction du drag, **réservé aux pets Codex** (aucun changement pour Cubee & co) ; **rendu toujours lissé**, pas de `image-rendering: pixelated`. | La sheet Codex n'a pas de ligne `sleeping` (9 lignes : idle, run-right, run-left, waving, jumping, failed, waiting, running, review). Le ratio cellule 192 px → `avatarSize` (slider) n'est pas entier : `pixelated` donnerait des pixels de largeurs inégales et un scintillement. Effets conservés par cohérence avec Cubee. Les lignes de course n'existent que côté Codex, d'où le périmètre limité. | `sleeping` = `waiting` ralentie ; couper les effets (le sprite a déjà `jumping`) ; `pixelated` automatique pour le pixel art ; `run-left/right` reporté ou étendu à Cubee. | actif  |
