# BDR-074 — Event `hooky-usage-error` dédié, message différencié sans détail CLI

| Décision                                                                                                                                                                                                                                                                                                                                  | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                                                                                           | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `spawn_usage_poller` émet `hooky-usage-error` (compteur d'échecs consécutifs) à chaque échec, en plus de `hooky-usage` sur succès. `useClaudeUsage` expose `consecutiveFailures`, `UsagePanel` affiche "Chargement…" tant qu'aucun échec n'est survenu, sinon "Quotas indisponibles" -- pas d'invite à relancer `claude` dans le message. | Le cache `LastUsage` ne bouge JAMAIS sur échec (cf. [BDR-071](../decisions/BDR-071.md)) -- avant ce fix, le front n'avait aucun signal distinguant "chargement en cours" de "échoue depuis 3h" (cf. [ZBLK-033](../archive/blockers/ZBLK-033.md), remonté par Baptiste : "tu as fait un code qui potentiellement ne fonctionne pas"). Le détail CLI est volontairement omis : reste cohérent avec le style minimaliste déjà établi du panneau (cf. [BDR-024](../decisions/BDR-024.md), [BDR-041](../decisions/BDR-041.md)) -- devient inutile si BDR-073 fonctionne, et un message technique dans une bulle décorative détonnerait avec le reste de l'UI. | Message invitant explicitement à relancer `claude` en terminal (proposé par Baptiste puis écarté par lui-même en cours de discussion) ; exposer un countdown avant le prochain essai (backoff) -- écarté, complexité non justifiée pour l'instant. | actif  |
