# LRN-078 — Champ API non vérifiable : parier défensivement, jamais crasher

| Pattern observé                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Sans accès pour valider la forme exacte d'une réponse API tierce, parier un nom de champ plausible (cohérent avec la convention déjà présente dans le payload) et coder défensivement — fallback silencieux si le champ est absent ou mal nommé, jamais de crash | Ajout de `resets_at` (temps de reset avant le prochain cycle de quota) dans `parseUsage` (`src/lib/usage.ts`), sans token ni accès réseau disponibles depuis l'environnement pour vérifier le payload réel de `api/oauth/usage` | Réutiliser ce pattern à chaque intégration d'API externe non testable directement dans l'environnement de dev : `champ?.optionnel ?? null` plutôt qu'un accès direct, et documenter l'hypothèse en commentaire pour que le prochain qui lit le code sache que c'est à vérifier |
