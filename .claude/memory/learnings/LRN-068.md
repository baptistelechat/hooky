# LRN-068 — Mesurer du texte avant `document.fonts.ready` mesure sur la police de repli, pas la police finale

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un élément texte utilisant une police web custom (`@font-face`, ici Geist Mono en `.woff2`) peut être mesuré (`offsetHeight`, retour à la ligne, etc.) AVANT que cette police soit effectivement chargée -- le navigateur rend alors avec une police de repli système, dont les métriques (largeur de caractère, hauteur de ligne) diffèrent, pouvant faire tenir le texte sur MOINS de lignes que le rendu final. | Fenêtre de notification Hooky : la hauteur mesurée pour dimensionner la fenêtre Tauri était parfois calculée avant le chargement de Geist Mono -- une fois la police chargée, le texte reflowait sur une ligne de plus, débordant du haut de la fenêtre déjà figée à la mauvaise taille. | Avant toute mesure de layout dépendant du rendu final d'un texte en police web custom, `await document.fonts.ready` en premier -- élimine la course entre chargement de police (asynchrone) et mesure (souvent synchrone dans un effet de montage). |
