# BDR-110 — Import Dots : la carte « + » colle, le fichier est secondaire

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                                  | Alternatives considérées                                                                                                                                                                              | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Dans la section Dots Lab, la carte « Coller un personnage » lit le presse-papiers (`navigator.clipboard.readText`), Ctrl+V importe depuis n'importe où dans l'onglet Avatar (listener `paste` sur le document, ignoré hors SVG et dans un champ de saisie), et l'import d'un fichier `.svg` est un bouton de l'en-tête. Un personnage collé s'appelle « Dots perso N », un fichier prend le nom du fichier ; pas de renommage. Suppression depuis la carte, avec confirmation. | Baptiste a corrigé ma première version, où la carte ouvrait un sélecteur de fichier : Dots Lab ne fournit pas de fichier pour la planche, il la copie (« Copy SVG sheet »). Le geste principal doit donc être le collage. | Carte = fichier et bouton d'en-tête = coller (première version, écartée par Baptiste). Plugin presse-papiers de Tauri (non retenu tant que l'API web suffit : dépendance Rust et capability en plus). | actif  |
