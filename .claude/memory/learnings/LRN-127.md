# LRN-127 — Calquer un import sur le geste réel de l'outil source

| Pattern observé                                                                                                                                                                                                                                                                                                                                     | Contexte                                                         | Application future                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Deux erreurs dans la première version de l'import Dots Lab. J'ai repris le pattern existant « carte + = sélecteur de fichier » alors que l'outil source copie son export dans le presse-papiers ; et j'ai écrit un chemin de menu faux (« menu SVG ») repris d'un README de la session précédente, au lieu du libellé réel (« Copy animated SVG »). | Baptiste a relevé les deux à l'essai, capture d'écran à l'appui. | Avant de concevoir un import depuis un outil tiers, regarder ce que l'outil remet réellement à l'utilisateur (presse-papiers, fichier, zip) et faire de ce geste l'action principale. Tout libellé d'interface tiers cité dans l'app se vérifie sur l'écran de l'outil, pas dans une doc interne. |
