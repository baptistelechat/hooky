# BDR-106 — Verrou anti-concurrence sur le spawn du menu contextuel

| Décision                                                                                                                                                                                                                                                                   | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Alternatives considérées                                                                                                                                                                                                                                   | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `spawnContextMenuWindow` (`src/lib/contextMenuWindow.ts`) est encadrée par un verrou de module (`let spawning = false` + try/finally), qui ignore tout appel entrant tant qu'un spawn précédent n'est pas terminé (close de l'ancienne fenêtre + création de la nouvelle). | Baptiste a signalé un crash natif WebView2 (`null pointer dereference` / `STATUS_STACK_BUFFER_OVERRUN`) au lancement de l'app puis en retestant le clic droit sur le pet. Sans verrou, un clic droit répété rapidement pouvait déclencher deux `close()`+`new WebviewWindow("menu")` en parallèle sur le même label — collision native non rattrapable côté JS. Le pattern existait déjà ailleurs dans le projet (`useBubbleWindow`, anti-double-spawn StrictMode) mais pas sur ce spawn-ci. | Debounce sur `onContextMenu` : écarté, retarderait l'ouverture du menu même en usage normal, pas seulement en cas de clic répété. Lock côté Rust dans `watch_menu_dismiss` : écarté, la collision se joue côté JS au moment du spawn, pas de la fermeture. | actif  |
