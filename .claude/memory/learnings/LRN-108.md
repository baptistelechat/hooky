# LRN-108 — vite.config.js versionné, réécrit à chaque pnpm build

| Pattern observé                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                                                                                                                                                                          | Application future                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vite.config.js` est un fichier **généré mais versionné** : `tsconfig.node.json` est en `composite: true` sans `noEmit`, donc `tsc -b` (première étape de `pnpm build`) le réécrit à côté de `vite.config.ts`. Le recompilé diffère du committé (~250 lignes d'aides `__awaiter`/`__generator`) même sans changement de source. | Après le `pnpm build` de la gate lint + build du retrait des orbs, `git status` montrait ` M vite.config.js` (180 insertions, 77 suppressions) alors que le spike n'y avait touché que 3 lignes. Vérifié dans `tsconfig.node.json` (`include: [vite.config.ts]`). | Après chaque `pnpm build`, regarder `git status` : si `vite.config.js` est modifié sans que `vite.config.ts` le justifie, le restaurer (`git checkout HEAD -- vite.config.js`). Pour changer la config Vite, éditer les deux fichiers à la main, comme l'a fait le spike. Un vrai correctif (`noEmit`, ou retirer le `.js` du dépôt) reste à décider séparément. |
