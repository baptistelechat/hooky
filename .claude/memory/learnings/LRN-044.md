# LRN-044 — Champs officiels Claude Code hooks `stop_hook_active`/`prompt_id` utiles pour diagnostiquer un doublon de Stop

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le payload du hook `Stop` inclut un champ officiel `stop_hook_active` (bool — indique si Claude Code réinvoque le hook dans le cadre de sa propre boucle anti-blocage, plafonnée à 8 invocations consécutives). Tous les hooks incluent aussi un `prompt_id` (UUID du prompt utilisateur actif, corrèle plusieurs hooks du même tour). Aucun des deux n'apparaît en survolant la doc en premier réflexe — il a fallu les chercher spécifiquement via une recherche documentaire ciblée. | Diagnostic d'un Stop/son/notification joué en double dans Hooky. Logguer ces deux champs a permis d'écarter l'hypothèse "boucle anti-infinie côté Claude Code" (`stop_hook_active=false` confirmé sur le Stop en cause) et de recentrer l'investigation sur le backend applicatif (reaper désynchronisé, cf. [LRN-040](LRN-040.md)). | Face à un event Claude Code `Stop`/`SubagentStop` qui semble se déclencher plusieurs fois, logguer `stop_hook_active` et `prompt_id` en premier réflexe avant toute hypothèse (fork invisible, interférence cross-session, race frontend) — ces champs officiels tranchent rapidement plusieurs classes d'hypothèses sans instrumentation lourde. |
