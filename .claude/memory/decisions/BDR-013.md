# BDR-013 — SessionStart et quota_auto_resume_fired : mapping corrigé après validation visuelle

**Décision** : `SessionStart` passe de `waking` à `listening` ; `quota_auto_resume_fired` passe de `waking` à `bored` (`animation_for_event()`, `src-tauri/src/lib.rs` + `docs/EVENTS.md`). `waking` n'est donc plus produit par aucun event, retiré de `STATE_PRIORITY`

**Pourquoi** : Confirmé visuellement par Baptiste via la grille de validation ([BDR-012](BDR-012.md)) : le rendu de `waking` ne correspondait pas à ce que son nom promettait dans ces deux contextes

**Alternatives considérées** : Garder `waking` pour au moins un des deux events (écarté, confirmation directe des deux corrections) ; retirer complètement `waking` de la palette du moteur (non fait — reste disponible dans `avatar.json`, juste plus câblé nulle part, cf. section "Volontairement non mappé" de `docs/EVENTS.md`)
