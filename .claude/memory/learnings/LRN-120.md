# LRN-120 — Chaque fenêtre Tauri secondaire rouvre le menu natif WebView2

| Pattern observé                                                                                                                                                                                                                                                                                                             | Contexte                                                                      | Application future                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Le blocage du menu natif WebView2 (Actualiser, Enregistrer sous, Imprimer, Inspecter) par `onContextMenu` + `preventDefault` est propre à un webview. La fenêtre « main » le bloquait déjà, mais la nouvelle fenêtre « menu » (autre webview) laissait un clic droit sur le menu rouvrir le menu natif, avec « Inspecter ». | Fenêtre « menu » du pet : Baptiste a pu faire un clic droit dessus (capture). | À chaque nouvelle fenêtre Tauri (label rendu dans `App.tsx`) : poser `document.addEventListener("contextmenu", e => e.preventDefault())` dans son composant, sur le document (couvre popup et marge transparente), pas sur un élément. Reste à faire pour les fenêtres « bubble » et « settings » si on veut la même garantie. |
