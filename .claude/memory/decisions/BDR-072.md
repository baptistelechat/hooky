# BDR-072 — `docs/RELEASING.md`, checklist de release répétable en 8 étapes

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Pourquoi                                                                                                                                                                                                                                                                                                           | Alternatives considérées                                                                                                                                                                                                                                       | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `docs/RELEASING.md` créé : checklist de 8 étapes (vérifier le changelog → générer la description de fusion via `/pr-description-writer` → merger `development` dans `main` (CLI, SourceGit ou PR GitHub) → bumper la version → pousser le tag → publier la release GitHub → purger les branches mergées → resynchroniser `development` sur `main`). Commandes de purge en PowerShell natif (`Where-Object`/`ForEach-Object`), pas bash/`grep`/`xargs` -- le terminal réel de Baptiste est PowerShell. | Le processus de release existait déjà mais dispersé dans 3 décisions distinctes ([BDR-064](../decisions/BDR-064.md), [BDR-067](../decisions/BDR-067.md), [BDR-068](../decisions/BDR-068.md)) sans procédure actionnable unique -- risque d'oublier une étape (ex. resync `development`) à chaque nouvelle version. | Se fier à la mémoire/aux BDR existants à chaque release -- rejeté, même logique que [BDR-067](../decisions/BDR-067.md) (éliminer l'oubli récurrent) ; commandes bash dans la doc -- rejeté après un essai réel raté (`grep: command not found` en PowerShell). | actif  |
