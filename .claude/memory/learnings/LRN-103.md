# LRN-103 — Licence d'un composant copié : lire l'en-tête des fichiers

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Contexte                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La licence annoncée par un site ou un registre (ici MIT, page d'accueil et `LICENSE` du repo) peut ne couvrir que son propre code : les fichiers portés depuis un tiers portent leur propre restriction dans un commentaire d'en-tête. Sur shadercn, les 33 `gpu.ts` disent « Non-commercial use only, with attribution to XorDev », alors que `llms-full.txt`, `installation.md` et la page d'accueil n'en parlent pas (seulement l'attribution). Le slogan « Own Your Code » décrit le mode de distribution, pas les droits sur les shaders. | Évaluation des orbs pour Hooky, repo AGPL public : une clause non-commerciale contredit l'AGPL (pas de restriction supplémentaire). Trouvée en lisant `https://www.shadercn.run/r/orb-XX.json`, pas la doc. | Avant d'embarquer du code copié (registry, snippet, shader), grepper les en-têtes des fichiers (`licen`, `commercial`, `permission`, auteur) sur **tous** les éléments visés, pas un échantillon ; comparer avec la licence du projet receveur ; citer la source exacte à l'utilisateur. Une attribution visible ne lève jamais une clause non-commerciale. |
