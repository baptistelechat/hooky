# LRN-004 — Avatar Hooky "qui disparaît" en dev = rebuild `tauri:dev` tue le backend, pas un bug

| Pattern observé                                                                   | Contexte                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La fenêtre pet disparaît puis réapparaît en `sleeping` pendant une session de dev | Relancer `tauri:dev` (ou modifier du code sous `src-tauri/`) déclenche un rebuild Rust complet ; l'ancien `hooky.exe` (donc le serveur axum sur 4242) meurt le temps de la recompilation → tous les hooks Claude Code échouent en `ECONNREFUSED` (visible dans le panneau Claude Code), la fenêtre native disparaît avec le process. Au redémarrage, la map de sessions repart vide → l'état retombe sur `sleeping` par défaut jusqu'au prochain event. Plus généralement : un rebuild `tauri dev` tue et relance tout le process, donc toute ressource stateful côté Rust perd son état — ce n'est pas un hot-reload partiel comme côté frontend Vite | Avant de chercher un bug frontend quand l'avatar "disparaît" en dev : vérifier le terminal `tauri:dev` pour un rebuild en cours (`Compiling hooky v0.1.0...`). Si oui, attendre `Finished ... Running target\debug\hooky.exe` — comportement attendu, rien à corriger. Ne pas concevoir de state côté Rust qui suppose une persistance entre rebuilds dev |
