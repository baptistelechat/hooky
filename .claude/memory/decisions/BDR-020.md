# BDR-020 — Icônes de badge toujours visibles pendant que Claude travaille

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                                                                                                    | Alternatives considérées                                                                                                                                                                                                                                                                                                             | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| `PostToolUse`, `PostCompact` et `SubagentStop` reprennent l'icône `Brain` déjà utilisée par `UserPromptSubmit` dans `animationCatalog.ts` — ces trois hooks correspondent à une pause transitoire entre deux actions dans un flux toujours actif (animation `idle`), pas à une vraie fin de tâche. Seuls `Stop` (animation `celebrate` déjà distinctive) et les vrais états de repos (`bored`, `idle` de conclusion côté `Notification` : `elicitation_complete`, `elicitation_response`, `auth_success`, `agent_completed`) restent sans badge. | Demande explicite de Baptiste : avoir un icône affiché en continu tant qu'une session Claude Code travaille, pour que l'absence de badge signale sans ambiguïté un vrai repos plutôt qu'une simple pause entre deux outils. | Dériver l'icône directement du bucket d'animation `idle` (rejeté : casserait [BDR-015](../decisions/BDR-015.md), plusieurs hooks partagent `idle` sans avoir le même sens) ; créer une icône dédiée par hook plutôt que réutiliser `Brain` (jugé superflu, `Brain`/"réflexion entre deux actions" convient sémantiquement aux trois) | actif  |
