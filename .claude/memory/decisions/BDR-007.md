# BDR-007 — Fenêtre settings : native séparée (WebviewWindow), localStorage seul

**Décision** : La fenêtre de paramètres Hooky est une vraie fenêtre Tauri native (`WebviewWindow` créée dynamiquement en JS, même bundle que le pet, routage par label de fenêtre) et non un panneau embarqué dans les 240×240 du pet ; stockage purement `localStorage`, pas de backend/sync multi-PC

**Pourquoi** : Baptiste a explicitement confirmé que la synchro multi-PC n'était pas un besoin pour ce projet perso ; export/import JSON couvre le besoin de sauvegarde/portabilité en secours

**Alternatives considérées** : Panneau embarqué dans la fenêtre 240×240 du pet (rejeté : trop petit pour des contrôles shadcn confortables) ; stockage cloud ou fichier de config dédié (rejeté : sur-ingénierie pour un besoin non exprimé)
