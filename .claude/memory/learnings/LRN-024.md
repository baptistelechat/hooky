# LRN-024 — Bug non-déterministe/asynchrone : prendre le contrôle du process + rejouer des payloads synthétiques plutôt que théoriser

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Contexte                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Face à un bug d'agrégation d'état multi-session, plusieurs hypothèses successives (config identique rejetée par Baptiste, mécanisme interne réfuté par la doc officielle) n'ont rien confirmé. Baptiste a explicitement demandé d'arrêter de deviner. Solution : tuer le process serveur de Baptiste, ajouter un log de debug temporaire, lancer le binaire soi-même en arrière-plan (accès direct à stdout/stderr), puis rejouer des payloads isolés (curl) dans un seul appel d'outil (pour ne pas polluer le test avec ses propres events de session) | Diagnostic d'un bug de course/agrégation dans le serveur axum de Hooky où la cause n'était pas repérable par relecture de code seule (dépend de l'ordre d'arrivée réel des requêtes réseau) | Après 2 hypothèses non vérifiées sur un bug non-déterministe (timing, concurrence, événements externes), privilégier un test isolé et reproductible — prendre le contrôle du process concerné, instrumenter avec un log ciblé, puis rejouer la séquence exacte suspectée — plutôt que d'émettre une nouvelle théorie. Particulièrement après qu'un utilisateur a explicitement rejeté une explication non vérifiée |
