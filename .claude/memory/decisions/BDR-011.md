# BDR-011 — `celebrate` remplace `idle` sur `Stop`

**Décision** : `Stop` déclenche désormais l'animation `celebrate` (existait déjà dans l'export du moteur, 23 animations, jamais câblée) au lieu de `idle` ; `PostToolUse`/`SubagentStop`/`PostCompact` restent `idle`. Décroissance vers `bored` après `BORED_TIMEOUT` réutilisée telle quelle, aucun nouveau mécanisme ajouté

**Pourquoi** : Demande explicite de Baptiste : `Stop` est le seul moment où sa notification Windows perso ("Claude Code — terminé") se déclenche, jamais en cours de tâche — signal de fin fiable

**Alternatives considérées** : Réserver `celebrate` à un heuristique de succès plus fin ("Stop sans échec récent") — écarté : se déclencherait sur _chaque_ tour normal, perdant tout caractère distinctif, sans donnée de "significativité de la tâche" disponible côté Claude Code
