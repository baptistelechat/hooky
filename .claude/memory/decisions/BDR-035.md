# BDR-035 — Bulle de notification : fenêtre Tauri statique et autonome

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Pourquoi                                                                                                                                                                                                                                                                | Alternatives considérées                                                                                                                                                                                                                                                                                                  | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Nouvelle fenêtre `bubble` déclarée statiquement dans `tauri.conf.json` (`visible: false`), pas créée dynamiquement en JS comme la fenêtre `settings`. Entièrement autonome : écoute le même event `hooky-state` que le pet, lit la position de `main` via `WebviewWindow.getByLabel("main")`, calcule sa propre position (au-dessus/en-dessous, clampée au moniteur via `monitorFromPoint`), et s'affiche/se cache elle-même. Aucune commande Rust ni capability ajoutée sur `main`. | Une fenêtre statique existe dès le démarrage — pas de race sur la toute première notification (contrairement à une création à la demande). L'autonomie évite d'étendre la capability `main` avec des permissions de contrôle cross-fenêtre juste pour piloter la bulle. | Fenêtre créée dynamiquement au premier `show()` (comme `settings`, cf. [BDR-007](../decisions/BDR-007.md)) — rejetée pour le risque de race au premier hook. Bulle pilotée depuis `main` (main calcule position/show/hide) — rejetée, capability `main` inutilement élargie pour un rôle que la bulle peut assumer seule. | actif  |
