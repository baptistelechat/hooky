# BDR-001 — Moteur d'animation : Strobi/Cubee retenu (AGPL-3.0)

| Décision                                                                                                               | Pourquoi                                                                                                                                                                                                                                                     | Alternatives considérées                                                                                      | Statut |
| ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ------ |
| Copier le moteur `bible-strong-avatar-lab` (composant Strobi, renommé Cubee) dans `src/avatar/`, 4 fichiers tels quels | 23 animations nommées quasi 1:1 avec les états voulus (`sleeping`, `waking`, `idle`, `thinking`, `working`), wrapper React déjà écrit et robuste, moteur vanilla JS sans dépendance Motion/Framer contrairement à ce que laissait penser le README du Studio | `bloub` (MIT, Vue 3 — wrapper à réécrire), `blobatar` (licence non confirmée, CSS pur, mapping manuel requis) | actif  |

Le code étant copié (pas consommé comme dépendance npm), l'app entière devient une œuvre dérivée AGPL-3.0 dès qu'elle est distribuée. Le projet est destiné à être partagé publiquement (confirmé) → tout le repo Hooky passe en AGPL-3.0, en-têtes `NOTICE` créditant `smontlouis/bible-strong-avatar-lab` ajoutés dans les 4 fichiers de `src/avatar/`.
