# BDR-002 — Port axum fixe 4242, pas de fallback dynamique

| Décision                                                                              | Pourquoi                                                                                                                                                                                                                                                                          | Alternatives considérées                                                                                  | Statut |
| ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------ |
| Serveur axum démarré dans le `setup()` du `Builder` Tauri, bind fixe `127.0.0.1:4242` | Les hooks Claude Code (`~/.claude/settings.json`) pointent sur l'URL en dur — pas d'allocation de port dynamique possible côté client. Un bind qui échoue panique volontairement (conflit externe non résolvable proprement, protégé en amont par `tauri-plugin-single-instance`) | Port dynamique + découverte côté client (rejeté : complexité inutile pour un usage strictement localhost) | actif  |

Aucune exposition réseau externe : binding restreint à `127.0.0.1`. Un hook `http` qui échoue (app fermée, port injoignable) est traité par Claude Code comme une erreur non-bloquante — comportement safe par défaut assumé, pas de fallback notification native pour la V1.
