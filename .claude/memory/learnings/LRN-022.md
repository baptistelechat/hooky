# LRN-022 — Un timer de transition en vol doit être gardé, pas redémarré

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                | Contexte                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un pattern de transition en 2 temps (fade-out différé -> swap -> fade-in) piloté par un unique `setTimeout` relancé à chaque changement de valeur casse silencieusement si de nouveaux déclenchements arrivent plus vite que le délai : chaque nouveau timer annule le précédent avant qu'il ait pu remettre l'état "visible" à `true`, bloquant l'UI dans un état intermédiaire indéfiniment. | Badge d'icône de Hooky : deux hooks Claude Code déclenchés coup sur coup (plus vite que les 150ms du crossfade) laissaient le cercle du badge visible mais sans icône dedans ("badge blanc" en usage réel). | Garder une ref du timer déjà en vol et ne pas en relancer un second tant qu'il n'a pas committé (`fadeTimeoutRef`), combinée à une ref séparée pour la dernière valeur cible à appliquer quand le timer en cours se déclenche enfin (`pendingIconRef`). |
