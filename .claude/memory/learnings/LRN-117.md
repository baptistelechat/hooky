# LRN-117 — Tester un moteur audio sans oreille : Vite SSR + faux AudioContext

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                           | Application future                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Charger le **vrai** module (`src/lib/sounds.ts`) avec `vite.createServer({ middlewareMode: true }).ssrLoadModule(...)` (il gère `import.meta.glob`), après avoir posé en globals un faux `AudioContext`, `fetch` et `Audio` et une horloge audio simulée, puis **compter les sources audibles** (démarrées et pas encore stoppées) par scénario : rafale de démarrages, démarrages répétés, va-et-vient, changement de feel, arrêt. Résultat : 1 boucle pour 10 démarrages, 0 après arrêt, 2 pendant 0,6 s lors d'un fondu croisé. | Baptiste entendait des doublons et je ne pouvais pas écouter. Le script est resté dans le scratchpad (`loop-harness.mjs`), sans changer le projet ni ajouter de framework de test. | Pour valider une logique de lecture, compter des objets plutôt qu'écouter. **Limite** : ne voit ni les doublons entre fenêtres ni ceux dus au serveur de dev (LRN-116) ; il a écarté le moteur, pas le bug. Le résultat « pas de doublon durable » ne dit rien d'un chevauchement de fondus. |
