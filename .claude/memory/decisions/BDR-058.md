# BDR-058 — Clamp de drag sur l'union de tous les moniteurs (`availableMonitors()`), plus seulement le moniteur courant

| Décision                                                                                                                                                                                                                                                  | Pourquoi                                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                                                                                                                                                                                                 | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Le clamp de drag de l'avatar (`startClampedDrag`, cf. [BDR-044](BDR-044.md)) calcule désormais ses bornes sur l'union de TOUS les moniteurs (`availableMonitors()`, bounding box min/max en X/Y), converties avec le `scaleFactor` du moniteur de départ. | `currentMonitor()` seul renvoie uniquement le moniteur où la fenêtre se trouve AU MOMENT de l'appel -- sur une config multi-écran, Baptiste ne pouvait plus faire glisser l'avatar au-delà des bords de son écran principal, même vers un second écran physiquement adjacent. | Rester sur `currentMonitor()` seul -- écarté, c'est la cause directe du bug signalé. Reclamper dynamiquement à chaque frame vers le moniteur SOUS le curseur (`monitorFromPoint`) -- écarté, complexité inutile alors qu'un simple bounding box de tous les moniteurs suffit à couvrir le cas d'usage (bureau virtuel rectangulaire classique, pas de disposition en L). | actif  |

## Références

- Révise le clamp posé par [BDR-044](BDR-044.md) (drag piloté à la main)
- [LRN-055](../learnings/LRN-055.md) — le clamp doit border le bord réel du contenu, appliqué ici à l'échelle du bureau virtuel entier
