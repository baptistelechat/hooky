# LRN-060 — Tester Hooky depuis la session Claude Code qui le teste pollue le test

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                                                                                                                                                                                          | Application future                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Envoyer un event synthétique (curl/`Invoke-RestMethod`) au serveur local de Hooky depuis un OUTIL de la même session Claude Code que celle en train de piloter Hooky produit des faux négatifs intermittents : chaque appel d'outil de CETTE session émet lui-même de vrais hooks (`PreToolUse`/`PostToolUse`) vers le même serveur, avec un `session_id` différent mais un timing très rapproché de l'event de test. Le backend résout l'état agrégé sur "la session la plus récemment active" -- un hook réel arrivant juste après l'event de test masque son état côté résolution, et React 18 peut batcher les deux `setState` consécutifs du listener Tauri au point de ne jamais commiter le rendu intermédiaire (celui produit par l'event de test) avant le suivant. Résultat observé : le comportement attendu (bulle affichée, resize...) semble parfois ne pas se produire, alors que le code est correct. | Vérification d'un correctif sur la bulle de notification de Hooky : deux tests identiques (même event `Stop` synthétique) donnaient des résultats différents selon qu'un appel d'outil de CETTE session intervenait entre le trigger et la vérification. Isoler le trigger+poll dans UN SEUL appel PowerShell (sans round-trip d'outil Claude Code entre les deux) a rendu le test reproductible. | Pour tester Hooky (ou toute app qui observe l'activité de la session Claude Code elle-même) en envoyant des events synthétiques, grouper le trigger ET la vérification dans un seul appel d'outil -- chaque frontière d'appel d'outil de la session en cours est elle-même une source de hooks réels concurrents au test. |
