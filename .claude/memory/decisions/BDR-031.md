# BDR-031 — Deux niveaux de reset couleurs : icône carte immédiate, boutons footer confirmés

| Décision                                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                                                                                                                                                                       | Alternatives considérées                                                                                                                                                                                                         | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le reset (icône CCW) sur la carte d'un avatar édité agit immédiatement, sans confirmation. Les 2 boutons du footer ("Réinitialiser {avatar}", "Tout réinitialiser") passent par un `AlertDialog` de confirmation avant d'agir. | Baptiste a explicitement demandé une confirmation pour les boutons du footer ("il faut un dialog qui rappelle que les modifications précédentes sont perdues") mais pas pour l'icône de carte -- geste local sur un seul avatar, facilement refait en cas d'erreur, contrairement à "Tout réinitialiser" qui efface le travail sur tous les avatars d'un coup. | Confirmation partout (non demandée pour l'icône carte, aurait ajouté de la friction à un geste rapide) ; aucune confirmation nulle part (rejeté, cf. LRN-110 global -- action qui efface un travail d'édition = guard bloquant). | actif  |
