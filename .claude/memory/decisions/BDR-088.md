# BDR-088 — Carte « Aucune session » : rejoue idle_prompt

**Décision** : La carte « Aucune session » (en tête de `EVENT_ANIMATIONS`) rejoue `Notification` / `idle_prompt`, l'event réel qui produit `sleeping`, et non un `SessionEnd`.

**Pourquoi** : `resolve_state` donne la main à la session la plus récemment active : cliquer une carte force son état parce que la session de preview devient la plus récente. Un `SessionEnd` supprime cette session et laisse les vraies sessions décider, donc le sommeil n'était visible qu'en fermant toutes les sessions Claude Code, alors que l'onglet sert justement à forcer un état.

**Alternatives considérées** : `SessionEnd` (première version, écartée) ; une commande Tauri qui force l'état (changer le backend pour un besoin de test) ; ne pas ajouter de carte (la carte `idle_prompt` existait déjà, mais peu découvrable).
