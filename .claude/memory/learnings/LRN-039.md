# LRN-039 — Contenu collé au bord plutôt que centré dans un conteneur surdimensionné

| Pattern observé                                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                         | Application future                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une fenêtre/conteneur volontairement plus grand que son contenu réel (pour éviter de mesurer dynamiquement) laisse un espace transparent invisible qui se lit comme un vrai espacement visuel si le contenu est centré dedans — aligner le contenu au bord concerné (`items-end`/`items-start` selon le point d'ancrage) supprime cet espace perçu sans rien mesurer. | Bulle de notification Hooky positionnée au-dessus ou en-dessous du pet selon la place disponible — fenêtre fixe 300×90, contenu réel ~40-50px de haut ; Baptiste a signalé un gap visible entre la bulle et le pet avant ce fix. | Pour tout conteneur à taille fixe volontairement généreuse (évite la mesure dynamique de contenu), toujours aligner le contenu vers le bord "significatif" plutôt que centrer par défaut. |
