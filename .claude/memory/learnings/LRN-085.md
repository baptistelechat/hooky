# LRN-085 — Tester un appel réseau sensible hors code prod, avec backup/restore

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                   | Contexte                                                                                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avant d'écrire le code Rust de refresh OAuth (cf. [BDR-073](../decisions/BDR-073.md)), tentative de valider l'endpoint en PowerShell direct (`Invoke-RestMethod` avec le vrai `refreshToken`) -- backup de `.credentials.json` fait avant, action bloquée une première fois par le classifier auto-mode (exfiltration potentielle de secret vers un endpoint réseau), débloquée après confirmation explicite de Baptiste en chat. | Un refresh_token OAuth est souvent à usage unique/rotatif côté serveur -- tester "pour voir" sans plan de restauration peut invalider silencieusement l'accès réel de l'utilisateur si la réponse n'est jamais réappliquée au fichier. | Avant tout test touchant un fichier de credentials réel (OAuth, API keys, sessions) : 1) backup explicite, 2) le garde-fou de permission qui bloque l'action est un signal à respecter, pas à contourner -- demander confirmation explicite en chat plutôt que chercher un détour, 3) si le test réussit, réappliquer immédiatement le résultat (ne pas laisser un token tourné non persisté). |
