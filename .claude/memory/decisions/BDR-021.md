# BDR-021 — Double-clic sur l'avatar : toggle focus/minimize de la fenêtre settings

| Décision                                                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                                                                             | Alternatives considérées                                                                                                                                     | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| `openSettingsWindow()` (`Avatar.tsx`) vérifie `existing.isFocused()` avant d'agir : si la fenêtre settings a déjà le focus, le double-clic la `minimize()` ; sinon `show()`/`unminimize()`/`setFocus()` la ramène au premier plan (comportement existant, [LRN-016](../learnings/LRN-016.md)) ; si elle n'existe pas encore, création inchangée. | Demande explicite de Baptiste, pattern familier d'une icône de taskbar déjà active qu'on re-clique pour la réduire — évite d'avoir à minimiser manuellement la fenêtre settings pour revenir au pet. | Toggle basé sur `isMinimized()` plutôt que `isFocused()` (écarté : ne couvre pas le cas où la fenêtre est visible mais en arrière-plan, sans être minimisée) | actif  |

## Références

- [LRN-016](../learnings/LRN-016.md) — pattern show+unminimize+setFocus déjà établi pour le cas focus
- [ZBLK-010](../archive/blockers/ZBLK-010.md) — bug de permissions découvert en implémentant ce toggle
