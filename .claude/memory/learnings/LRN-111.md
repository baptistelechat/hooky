# LRN-111 — Vérifier un installateur GUI : lancer, capturer, tuer

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                               | Application future                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Un installateur graphique se vérifie sans l'installer : le lancer avec `Start-Process -PassThru`, attendre 2 à 3 s, capturer l'écran (`System.Windows.Forms.Screen` + `Graphics.CopyFromScreen`, enregistré en PNG dans le scratchpad), puis `Stop-Process`. Énumérer les fenêtres (`EnumWindows`) ne montre pas leur contenu et renvoie un titre trompeur. Pour séparer « la config est mauvaise » de « l'état de la machine masque le comportement », compiler un mini `.nsi` (`MUI2` + la même macro) avec le `makensis.exe` de `%LOCALAPPDATA%\tauri\NSIS` et le lancer de la même façon. | Sélecteur de langue qui ne s'affichait pas : la capture a montré directement la page Bienvenue sans boîte, le mini-installateur a prouvé que la config était correcte. | Avant d'accuser la configuration d'un installateur, capturer l'écran au lancement plutôt que d'attendre le retour de l'utilisateur. Toujours tuer le processus avant l'écran de copie : à ce stade rien n'est encore installé. |
