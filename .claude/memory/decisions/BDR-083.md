# BDR-083 — Pets Codex : surcharge par hook seulement là où elle diffère de l'état

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                              | Alternatives considérées                                                                                                                                                               | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Niveau C de la table Codex (`codexAnimation` sur les entrées du catalogue) : posé **uniquement** quand la ligne diffère du repli par état (niveau B, `STATE_TO_ROW`). Résultat : 3 surcharges seulement, `SessionStart`, `auth_success` et `quota_auto_resume_fired` → `waving`. `codexOverrideFor(entry, animation)` ne l'applique que si l'état agrégé est celui que ce hook produirait seul. `findMappingEntry` reste inchangé. Tranché à l'usage : `bored` → `idle`, `waving` en boucle sur `SessionStart`. | Les autres surcharges envisagées dans la roadmap (`Stop`→`jumping`, échecs→`failed`, attentes→`waiting`) sont déjà données par le niveau B : les dupliquer n'apporterait rien et doublerait la maintenance. Sans la garde sur l'état agrégé, une autre session active ferait jouer au pet la ligne d'un hook qui n'est pas celui qui décide de l'état affiché (même risque que `PreToolUse` dans `findMappingEntry`). | Surcharger toutes les entrées comme prévu à l'origine ; étendre `findMappingEntry` pour porter la logique ; une seule table par état (perd la distinction `SessionStart` / `waiting`). | actif  |
