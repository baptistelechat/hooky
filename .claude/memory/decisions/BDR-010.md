# BDR-010 — SessionStart : hook `command`+`curl` au lieu de `http` natif

| Décision                                                                                                                                                                                                                                     | Pourquoi                                                                                                                                                                                                                                          | Alternatives considérées                                                                                                                                                                                                                                                    | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `docs/hooks/claude-settings-snippet.json` : le hook `SessionStart` passe de `type: "http"` à `type: "command"` (`curl -s -m 5 -X POST http://127.0.0.1:4242/event -H "Content-Type: application/json" -d @-`, lit le JSON du hook sur stdin) | Claude Code v2.1.51+ bloque silencieusement les hooks `http` sur `SessionStart`/`Setup` (restriction de sécurité non documentée) — confirmé empiriquement (instrumentation du backend) puis via issue GitHub #28044 et fetch direct de `hooks.md` | Script PowerShell personnel dans `~/.claude/settings.json` (première solution, fonctionnelle) — rejetée par Baptiste : Hooky est un projet destiné à être partagé publiquement, la solution doit marcher pour n'importe quel utilisateur/poste sans script bespoke à copier | actif  |

Tous les autres events du snippet restent en `type: "http"` natif, qui fonctionne
normalement partout ailleurs. `curl` est préinstallé sur Windows 10+/macOS/Linux, donc la
solution reste portable sans dépendance ajoutée.
