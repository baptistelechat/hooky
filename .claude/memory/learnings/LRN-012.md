# LRN-012 — Tauri `WebviewWindow` : `maxWidth` silencieusement ignoré sans `maxHeight` pairé

| Pattern observé                                                                                                                                                                                                                                                                                                                                           | Contexte                                                                                                                                                       | Application future                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dans l'API JS Tauri v2 (`WebviewWindow`/`WindowOptions`), la propriété `maxWidth` ne prend effet que si `maxHeight` est également fournie (et vice-versa) — documenté dans le JSDoc du type (`"Only applies if maxHeight is also set"`) mais facile à manquer, silencieusement ignoré sinon (pas d'erreur, la fenêtre reste redimensionnable sans limite) | Fenêtre settings Hooky plafonnée à 620px de large pour garder une grille CSS à 3 colonnes max — `maxWidth: 620` seul n'aurait rien fait sans `maxHeight` pairé | Toujours définir `maxWidth` et `maxHeight` ensemble (même généreux/peu contraignant sur l'axe non désiré) dans toute config `WebviewWindow`/`Window` Tauri — même dépendance croisée documentée pour `minWidth`/`minHeight` |
