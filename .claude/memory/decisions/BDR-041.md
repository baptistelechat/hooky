# BDR-041 — Bulle de notification : pas de lib toast/animation, tout en CSS/JS natif

| Décision                                                                                                                                     | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Alternatives considérées                                       | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------ |
| Garder `NotificationBubble` custom ; effets (pop, typing, pointe, pause hover) en Tailwind/CSS/`setInterval` natif, sans nouvelle dépendance | La bulle est ancrée dynamiquement sur l'avatar (position dépend de `avatarSize`), n'a jamais qu'une instance à la fois, et est déjà pilotée par un state machine événementiel (`revision`, cf. `useHookyState`). Les libs de toast (Sonner, Goey) sont conçues pour empiler des notifications en coin de viewport avec queue — cette valeur ne s'applique pas ici, il faudrait réécrire leur positionnement pour rien. Idem animation : les `arbitrary values` Tailwind (`ease-[cubic-bezier(...)]`) + un `setInterval` suffisent pour le pop d'entrée et le streaming de texte, pas besoin de framer-motion/react-spring. | Sonner, Goey (toast) ; framer-motion, react-spring (animation) | actif  |
