# LRN-026 — Tailwind v4 : `scale`/`rotate` sont des propriétés CSS natives, pas `transform`

| Pattern observé                                                                                                         | Contexte                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hover:scale-105` ajouté sans effet visible malgré `transition-[width,height,background-color,transform]` sur l'élément | Squash au hover/drag de l'avatar (`Avatar.tsx`) — Tailwind v3 composait `scale`/`rotate`/`translate` dans la propriété `transform`, Tailwind v4 les émet en propriétés CSS natives séparées (support navigateur désormais suffisant) | Pour transitionner `scale-*`/`rotate-*`/`translate-*` en Tailwind v4, lister la propriété CSS native correspondante (`scale`, `rotate`, `translate`) dans `transition-[...]` — jamais `transform`. Même piège pour `drop-shadow-*`/`brightness-*` → propriété `filter` |
