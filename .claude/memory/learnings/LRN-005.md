# LRN-005 — Reset global CSS → attributs `class` Tailwind sur `index.html`, en préservant la spécificité

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                   | Application future                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un reset CSS global (`:root`/`html`/`body`/`#root`) est migrable en Tailwind pur : poser les classes directement en `class=` sur `<html>`/`<body>`/`#root` dans `index.html`, et gérer les propriétés sans utilitaire dédié (text-shadow custom, empilement de polices non-standard) via la syntaxe arbitraire `[propriété:valeur]` / `font-[...]`. Point de vigilance : un ancien `:root{...}` (pseudo-classe, poids CSS = classe) a une spécificité plus forte qu'un `html{...}` en CSS pur (sélecteur de type) — le migrer vers une classe Tailwind sur `<html>` (qui génère aussi un sélecteur de poids "classe") préserve ce comportement de cascade, alors qu'un simple déplacement vers une règle `html{}` "propre" l'aurait cassé silencieusement. | Projet Tauri Hooky, refonte de `App.css` (resets globaux + 3 classes composant) en 100% Tailwind à la demande de Baptiste. | Sur ce projet (et tout projet Tailwind/Vite similaire), éviter de recréer un fichier `.css` pour les resets `html`/`body`/`#root` — les poser en `class=` dans `index.html`. Vérifier la spécificité d'origine (`:root` vs `html`) avant de migrer, pas juste la valeur visuelle. |
