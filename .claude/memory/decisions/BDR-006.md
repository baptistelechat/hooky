# BDR-006 — Mapping des hooks Claude Code finalisé (étape 8 du roadmap)

**Décision** : 7 events supplémentaires mappés dans `animation_for_event()` (`StopFailure`, `SubagentStart`, `SubagentStop`, `PreCompact`, `PostCompact`, `PermissionRequest`, `Elicitation`), tous sur la palette d'animations existante (aucune nouvelle animation) ; ~14 autres events retournés par une recherche documentés comme volontairement exclus

**Pourquoi** : Ferme le backlog "étape 8" (déjà identifié dans le roadmap initial) sans ajouter de bruit ni dépendre d'events dont l'existence même comme hook officiel n'était pas certaine

**Alternatives considérées** : Mapper tous les ~20 events retournés par l'agent de recherche (rejeté : risque d'enregistrer des hooks pour des events potentiellement fictifs/non vérifiés) ; ne rien ajouter (rejeté : demande explicite de finalisation)
