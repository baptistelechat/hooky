# BDR-043 — `AnimationOverlay` reçoit `showDebugZone` en prop plutôt que de lire `useSettings()` en interne

| Décision                                                                                                                                          | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                            | Alternatives considérées                                                                                                                           | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `AnimationOverlay` reçoit un prop `showDebugZone` explicite (défaut `false`) au lieu de lire `settings.debugMode` via `useSettings()` en interne. | Le composant est aussi rendu dans les cartes de preview d'animation des Settings (`AnimationCard.tsx`) — lire l'état global directement faisait fuiter le mode debug de la fenêtre pet vers ces previews, qui ne doivent jamais l'afficher (signalé par Baptiste : étiquette "badge" visible à tort dans les previews). Cohérent avec le reste du composant, déjà entièrement threadé en props (`enabled`, `avatarSize`, `icon`, `badgeIconColor`). | Condition ad-hoc pour détecter le contexte (ex: comparer `avatarSize` à une constante) — écarté, implicite et fragile comparé à un prop explicite. | actif  |
