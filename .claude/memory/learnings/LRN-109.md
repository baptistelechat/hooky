# LRN-109 — Habillage NSIS Tauri : BMP 24 bits sans alpha, tailles imposées

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                       | Application future                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Les images de l'installateur NSIS doivent être des **BMP 24 bits sans alpha** : `sidebarImage` 164×314 (pages Bienvenue et Fin), `headerImage` 150×57 (pages internes, fond blanc). `installerIcon` / `uninstallerIcon` prennent un `.ico`. `System.Drawing` (PowerShell) suffit pour les produire depuis un PNG, sans dépendance. Le `Read` de Claude Code ne lit pas les BMP : les convertir en PNG dans le scratchpad pour les vérifier à l'œil. | Habillage de l'installateur de Hooky : logo, nom et sous-titre dessinés par `src-tauri/installer/gen-images.ps1` à partir de `icons/icon.png`. | Sur tout projet Tauri/Windows : partir de `gen-images.ps1` (`New-Bitmap` en `Format24bppRgb`, `Clear` avec la couleur de fond, `DrawImage`, `DrawString`). Vérifier le rendu en enregistrant aussi un PNG. Les BMP sont commités, pas régénérés par la CI (voir BDR-095). |
