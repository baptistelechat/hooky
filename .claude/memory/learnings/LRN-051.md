# LRN-051 — Composant partagé lisant une state globale la fuit dans tous ses usages

| Pattern observé                                                                                                                                                                                                                                                                                                   | Contexte                                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AnimationOverlay` lisait `settings.debugMode` via `useSettings()` en interne plutôt que de le recevoir en prop — n'importe quel contexte de rendu du composant héritait alors du mode debug global, y compris les cartes de preview d'animation des Settings, sans rapport avec le mode debug de la fenêtre pet. | Retour de Baptiste signalant l'étiquette "badge" affichée à tort dans les previews de l'onglet Animation des Settings (cf. [BDR-043](../decisions/BDR-043.md)). | Un composant partagé entre plusieurs contextes de rendu distincts doit recevoir tout état contextuel en prop explicite plutôt que de le lire via un hook global — lire l'état global couple silencieusement TOUS les usages du composant à une state qui n'a de sens que dans un seul de ces contextes. |
