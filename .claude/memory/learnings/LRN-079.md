# LRN-079 — Icône animée en boucle infinie ≠ glyphe statique ponctuel

| Pattern observé                                                                                                                                                                                                                          | Contexte                                                                                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un composant icône custom conçu pour boucler en continu (badge décoratif, `motion`, auto-loop au montage) n'est pas adapté à un glyphe statique ponctuel, même si le besoin visuel semble identique en surface ("sparkles" = "sparkles") | Composant `SparklesIcon` custom (`src/components/icons/sparkles.tsx`, `motion/react`, boucle infinie `repeat: Infinity`) déjà en place pour un badge décoratif (`AnimationOverlay`) ; besoin réel dans `UsagePanel` = une icône Fable statique dans un ring de 44px, pas d'animation continue voulue | Avant de réutiliser un composant custom déjà présent dans le repo, vérifier le comportement qu'il porte (animation, effet, contexte de montage/démontage) — préférer la version statique de la même lib d'icônes (ex. `lucide-react`) quand le nouveau contexte n'a pas besoin de ce comportement |
