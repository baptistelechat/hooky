# LRN-091 — Frames par ligne variables selon le pet : les compter

| Pattern observé                                                                                                                                                                                                                                                                                             | Contexte                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le nombre de frames d'une ligne de spritesheet varie d'un pet à l'autre : `idle` compte 6 cellules pleines sur `work-blue-cat` (v1) et 7 sur `om-nom` (v2), mesuré en comptant les cellules dont l'alpha dépasse un seuil. Une table `CODEX_ROWS` aux `frames` figés ne joue jamais la 7ᵉ frame d'`om-nom`. | Session 1 des pets Codex : la table venait de pets de même génération, ce que la comparaison avec un pet v2 a contredit. Un seul exemple de chaque : impossible de dire si c'est une différence de version ou propre au pet. | Compter les cellules pleines par ligne (même passe canvas que `spriteColor.ts`) plutôt que figer `frames` ; plus généralement, avant de figer une constante déduite d'échantillons, en mesurer d'au moins deux origines différentes. À traiter en session 2/3 (cf. risques du roadmap). |
