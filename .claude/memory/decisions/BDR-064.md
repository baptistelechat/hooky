# BDR-064 — Checklist V0 partageable définie (`docs/RELEASE.md`), MAJ via check API GitHub

**Décision** : Checklist complète de distribution v0 formalisée dans `docs/RELEASE.md` (icônes custom, tray simplifié, packaging NSIS `currentUser`, auto-launch au 1er `SessionStart`, commande settings pour installer les hooks, CI GitHub Actions, LP optionnelle). Système de mise à jour : `fetch()` front vers `api.github.com/repos/.../releases/latest` + bouton "Vérifier les mises à jour" + badge persistant si outdated.

**Pourquoi** : Baptiste approche du lancement v0 et voulait s'assurer de ne rien oublier avant un partage public du repo (AGPL, `hooky.vercel.app` déjà nommé dans le brief).

**Alternatives considérées** : Plugin `tauri-plugin-updater` officiel — écarté : signature ECDSA obligatoire par build + `latest.json` à maintenir manuellement, disproportionné puisque le besoin réel est juste une redirection vers la page de release (pas d'install silencieuse).
