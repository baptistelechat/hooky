# LRN-030 — Rebuild coûteux dans un hook doit se mémoïser sur des primitives, pas l'objet source

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                             | Application future                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Appeler une fonction de construction coûteuse (ici `createAvatar()`, reconstruit tout un arbre SVG React) directement dans le corps du composant sans `useMemo` la rejoue à CHAQUE re-render, pas seulement quand ses dépendances "logiques" changent -- surtout si l'objet source est recréé structurellement à chaque event externe (ici, désérialisation IPC Tauri) même quand son contenu réel n'a pas changé. | `getAvatarBundle(avatarId, colorOverride)` appelé sans memo dans `PetAvatar`/`AnimationCard` reconstruisait l'avatar à chaque re-render dès qu'un override de couleur était actif (chaque event Claude Code entrant), provoquant un lag perceptible en usage réel (cf. [ZBLK-015](../archive/blockers/ZBLK-015.md)). | Mémoïser sur les valeurs primitives réellement utilisées (pas l'objet conteneur), avec `useMemo`/dépendances explicites -- un objet recréé par (dé)sérialisation IPC ne garantit jamais la stabilité référentielle même à contenu identique. |
