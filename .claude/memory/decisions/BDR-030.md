# BDR-030 — Couleurs éditées par avatar, keyed avatarId (pas d'override global unique)

| Décision                                                                                                                                                    | Pourquoi                                                                                                                                                                                                                                                             | Alternatives considérées                                                                                                                                                                                                                                                    | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `avatarColorOverrides: Record<string, AvatarColorOverride>` dans `HookySettings` — la clé est l'avatarId, la valeur un override partiel `{ body?, eyes? }`. | Switcher d'avatar ne doit pas écraser l'édition en cours d'un autre avatar, et revenir sur un avatar déjà édité doit retrouver sa couleur sans ressaisie — le picker d'avatar (cf. [BDR-028](BDR-028.md)) permet déjà de basculer librement entre plusieurs avatars. | Un override global unique appliqué à l'avatar courant (rejeté : perdu/faux dès qu'on switch d'avatar) ; stocker les couleurs dans le JSON de l'avatar lui-même (rejeté : les fichiers `avatars/*.json` restent des exports statiques du Studio, jamais réécrits par l'app). | actif  |
