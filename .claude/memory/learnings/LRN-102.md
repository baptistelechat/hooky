# LRN-102 — Shaders TypeGPU : `unplugin-typegpu` avec `enforce: "pre"`

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Les fonctions `'use gpu'` de TypeGPU sont compilées en WGSL grâce à `unplugin-typegpu`. Sans lui : `Missing metadata for tgpu.fn function body`. Avec `typegpu()` sans option, le plugin passe après l'esbuild de Vite et ne transforme rien en dev ; `typegpu({ enforce: "pre" })` corrige. La doc de shadercn ne mentionne ni le plugin ni ce réglage (elle dit « pas de configuration de bundler »). | Intégration de `orb-01` dans Hooky (Vite 7). Vérifié : transformation OK en isolation, en `pnpm build` (`__tsover` présent dans le bundle) et en dev une fois le vrai serveur redémarré ([BLK-038](../blockers/BLK-038.md)). | Pour tout composant shadercn / TypeGPU : `pnpm add -D unplugin-typegpu`, `typegpu({ enforce: "pre" })` dans `vite.config.ts`, redémarrer complètement le dev server, puis contrôler la sortie servie. `vite.config.js` (émis par `tsc -b`) est suivi par git : il change aussi. |
