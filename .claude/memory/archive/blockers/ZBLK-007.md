# ZBLK-007 — Badge qui disparaît ~10s après chaque hook : fausses pistes avant le vrai bug

| Friction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Cause réelle                                                                                                                                                                                                                                                                                                                                          | Solution                                                                                                                                                                | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le badge d'icône du pet apparaissait puis disparaissait systématiquement quelques secondes après un hook, l'animation restant pourtant active (`hook: -` dans l'overlay debug). Premier diagnostic proposé (interférence entre la session Claude Code de l'agent en train de travailler et la session testée par Baptiste, agrégat multi-session dominé par la mauvaise session) -- explication plausible mais fausse, écartée par Baptiste qui a précisé tester depuis l'onglet Settings, indépendant du pet réel. | Le reaper backend (`spawn_idle_reaper`, tick 10s) réémettait `hooky-state` avec un payload tronqué (`{state}` seul, sans `lastEvent`/`toolName`/`notificationType`) dès qu'il détectait un changement par rapport à son propre suivi interne jamais synchronisé avec les émissions du handler principal -- cf. [LRN-017](../../learnings/LRN-017.md). | Factorisation de la construction du payload (`resolve_full_state()`) partagée entre `on_event` et le reaper -- les deux émettent désormais toujours le payload complet. | résolu |
