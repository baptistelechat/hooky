# LRN-067 — `getBoundingClientRect()` inclut les transforms CSS, `offsetHeight`/`scrollHeight` non

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                  | Contexte                                                                                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mesurer un élément DOM avec `getBoundingClientRect()` pendant qu'il porte encore une classe `transform: scale(...)` (état "caché" avant une animation d'entrée) renvoie la taille APRÈS transform -- 95% de la vraie taille pour un `scale-95`, par exemple. `offsetHeight`/`offsetWidth`/`scrollHeight` ignorent les transforms CSS (propriétés purement visuelles, sans effet sur le flux de layout) et renvoient la vraie taille de la boîte. | Fenêtre de notification Hooky : la hauteur mesurée pendant la phase "measuring" (bulle encore en `scale-95 opacity-0`, avant révélation) servait à dimensionner la fenêtre Tauri -- sous-dimensionnée de 5%, le contenu débordait (haut + `box-shadow` rognés) une fois passé à `scale-100`. | Pour dimensionner un conteneur (fenêtre, popup, modal) à partir de la taille RÉELLE d'un élément qui porte une transform d'entrée/sortie (`scale`, `translate`...), toujours mesurer via `offsetHeight`/`offsetWidth` (ou `scrollHeight`/`scrollWidth`), jamais `getBoundingClientRect()` tant que la transform "hors écran" est encore appliquée. |
