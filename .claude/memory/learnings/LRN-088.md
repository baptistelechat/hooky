# LRN-088 — Format d'un asset communautaire non documenté : le mesurer sur les fichiers réels

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                | Application future                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La doc Petdex n'était pas lisible (`WebFetch` ne renvoie que des métadonnées Next.js, page rendue côté client). Plutôt que de deviner la structure des spritesheets Codex, mesuré les 4 fichiers réels : en-tête RIFF/WebP lu en Python stdlib (chunk `VP8L` ou `VP8X`, dimensions et flag alpha) faute de PIL, plus ouverture de l'image avec `Read` pour voir la grille. Résultat : 1536×1872 identique sur les 4, donc 8×9 cellules de 192×208. Même mesure qui a révélé que l'`id` du `pet.json` ≠ nom du dossier. | Cadrage du support des pets Codex ([BDR-077](../decisions/BDR-077.md)) : aucune spec officielle lue, la structure repose entièrement sur l'observation. | Sans spec lisible, mesurer plusieurs échantillons réels (dimensions, canal alpha, champs des manifestes) et vérifier qu'ils partagent la même structure avant de la coder en dur. Consigner dans la doc du projet « mesuré sur N fichiers, pas officiel » et prévoir de rejeter proprement un asset hors format. Sans PIL, l'en-tête WebP se lit en quelques lignes de Python stdlib. |
