# LRN-047 — Élément décoratif absolu dans un parent `transform` se peint par-dessus son fond

| Pattern observé                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un enfant `position: absolute` d'un parent qui a lui-même un `transform` (scale/translate, donc son propre contexte d'empilement local) se peint PAR-DESSUS le fond de ce parent par défaut — même positionné à cheval sur son bord, le chevauchement seul ne le "cache" pas derrière. | Pointe de bulle de BD (`NotificationBubble`) censée se fondre dans le bas de la bulle : sans z-index négatif, elle apparaissait comme une forme flottante détachée devant la bulle malgré le chevauchement. | Donner un `z-index` négatif à l'élément décoratif chevauchant — le parent `transform` sert déjà de contexte d'empilement local (pas de fuite vers le reste de la page) — et lui donner exactement le même fond/bordure que le parent pour une fusion visuelle propre. |
