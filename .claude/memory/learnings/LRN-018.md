# LRN-018 — `fetch()` depuis une webview Tauri vers son propre backend local reste soumis au CORS

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Contexte                                                                                                                                                                                            | Application future                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un clic sur une carte de l'onglet Animation (settings) censé déclencher un event réel via `fetch(POST /event)` ne faisait rien, échec silencieux (try/catch avalait l'erreur). Cause : requête cross-origin depuis la webview settings vers `127.0.0.1:4242`, bloquée par le navigateur (WebView2) faute de headers CORS côté serveur -- alors que les vrais hooks Claude Code, envoyés en `curl`, n'ont jamais été concernés (pas de préflight CORS pour ce trafic-là). | Ajout de `tower_http::cors::CorsLayer::permissive()` côté axum a débloqué le clic-pour-tester. Le fait que le serveur fonctionne parfaitement pour les vrais hooks masquait totalement le problème. | Dès qu'une webview Tauri (ou tout frontend embarqué) doit appeler en JS le serveur local de sa propre application, prévoir du CORS côté serveur dès la conception -- ce n'est PAS parce qu'un autre type de trafic (CLI, curl) fonctionne déjà que l'appel JS interne fonctionnera. |
