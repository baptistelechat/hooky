# LRN-035 — Vérifier une fenêtre Tauri native via interop Win32 direct sans harness e2e

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sans Electron/Playwright ni claude-in-chrome (fenêtre Tauri = webview natif, pas un onglet Chrome), on peut quand même vérifier visuellement le rendu réel via PowerShell + interop Win32 (`Add-Type` inline) : `EnumWindows`+`GetWindowText`/`GetWindowRect` pour localiser une fenêtre par titre, `SetCursorPos`+`mouse_event` pour simuler un double-clic natif (déclenche l'ouverture de la fenêtre settings), `SetWindowPos` pour redimensionner, et `System.Drawing.Graphics.CopyFromScreen` pour capturer un screenshot exact de la zone, relu ensuite avec l'outil `Read` (image). | Vérifier que le repositionnement des boutons reset (`AvatarPicker.tsx`) rendait bien le layout attendu en fenêtre large ET étroite dans l'app Tauri réelle (pas seulement via lecture de code) -- `getCurrentWindow()` (`@tauri-apps/api/window`) plante hors contexte Tauri donc pas de fallback navigateur possible pour ce composant. | Pour toute vérification visuelle d'une app desktop native sans harness e2e existant : chaque appel `Add-Type` PowerShell doit être dans la MÊME commande (les types ne persistent pas entre appels de l'outil PowerShell) ; toujours combiner localisation de fenêtre + action + screenshot dans un seul script quand possible. |
