# LRN-089 — Clé Uninstall NSIS Tauri : InstallLocation entre guillemets

| Pattern observé                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avec `installMode: currentUser`, l'installeur NSIS de Tauri écrit `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<productName>` avec `InstallLocation` (chemin **entre guillemets**), `DisplayIcon`, `UninstallString` et `MainBinaryName` (`hooky.exe`, en minuscules). | Hooky installé sur D: chez un autre poste : le hook `SessionStart` qui lançait `%LOCALAPPDATA%\Hooky\Hooky.exe` échouait en silence. Résolu en lisant `InstallLocation` au lieu du chemin par défaut. | Pour localiser un exe Tauri/NSIS installé, lire cette clé plutôt que supposer `%LOCALAPPDATA%` : `(gp HKCU:\...\Uninstall\<productName>).InstallLocation.Trim([char]34)`. Une commande sans `$` ni guillemets imbriqués reste valide sous cmd comme sous bash. Pour tester un one-liner `cmd` aux guillemets imbriqués, éviter Git Bash (il les corrompt) : utiliser `ProcessStartInfo.Arguments` en PowerShell. |
