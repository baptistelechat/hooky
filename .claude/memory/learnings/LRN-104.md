# LRN-104 — Déboguer Tauri/WebView2 : `remote-debugging-port` + CDP

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                                                                                                   | Application future                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lancer l'app avec `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9222"` ouvre le protocole Chrome DevTools sur `http://127.0.0.1:9222/json`. Un petit script Node (WebSocket global, Node 24) sur `webSocketDebuggerUrl` suffit : `Runtime.evaluate` (`navigator.gpu`, DOM, opacité du canvas), `Runtime.consoleAPICalled` / `exceptionThrown` pour les erreurs, `Page.reload`. Chaque fenêtre Tauri est une cible distincte (main et Paramètres ont la même URL) : identifier la bonne par son DOM. Le flag `--enable-unsafe-webgpu` n'est pas nécessaire : WebGPU est actif par défaut. | Le navigateur intégré de Claude refuse les origines locales ([BLK-034](../blockers/BLK-034.md)) et ne voit de toute façon pas la vraie fenêtre Tauri ; un screenshot seul ne dit pas pourquoi un canvas est vide. Ici, CDP a donné en une passe l'exception TypeGPU, la taille du canvas et son `opacity`. | Pour toute vérification de rendu ou d'erreur JS dans la vraie fenêtre : définir la variable d'environnement dans le shell qui lance `tauri dev`, interroger CDP, puis capturer l'écran (bureau virtuel `SystemInformation.VirtualScreen`, l'écran peut être à x négatif) pour le visuel. Coût GPU : compteur `\GPU Engine(*)\Utilization Percentage` filtré par nom de process. |
