# BDR-099 — « Moins bavard » : essentiels gardés, défaut bavard

**Décision** : Réglage `soundQuietMode`, **désactivé par défaut** (tous les sons jouent). Activé, il ne garde que les cues **essentiels** (`start`, `wake`, `sleep`, `complete`, `mention`, `notification`, `error`) et coupe les secondaires (`send`, `checkpoint`, `unlock`, `play`, `invalid-drop`, `collapse`, `seek`, `progress-step`, `queued`). Les cues d'outils restent limités à un par 3 s dans tous les cas. Il remplace « Sons des outils » (opt-in, coupé par défaut). Pendant que l'onglet Animation est ouvert, mode discret et limite de 3 s sont levés pour que chaque carte sonne.

**Pourquoi** : Baptiste voulait la diversité par défaut et un bouton pour la réduire. L'opt-in cachait les sons d'outils : il les croyait cassés (`seek`, `progress-step`, `queued` « ne se lancent pas ») alors qu'ils étaient désactivés.

**Alternatives considérées** : Garder l'opt-in « Sons des outils » ; un curseur par catégorie (deux bus suffisent, cf. BDR-100).
