# BDR-004 — Migration du moteur copié vers le package npm `@bible-strong/avatar-react`

| Décision                                                                                                                                                                                                                                                                                                                                                             | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                           | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Remplacer le code copié à la main dans `src/avatar/` (moteur `avatar-runtime.ts` chargé via Blob + `import()` dynamique, données `cubee.avatar.ts` à IDs génériques) par la dépendance npm officielle `@bible-strong/avatar-react@0.1.0` + `createAvatar(definition)`, `definition` étant `cubee.avatar.json` exporté du Studio (schéma versionné, clés sémantiques) | `smontlouis/bible-strong-avatar-lab` a publié un package npm réel après le développement initial (vérifié publié sur le registry). Le nouveau JSON exporté couvre exactement les 9 animations utilisées par le backend Rust (`sleeping, waking, idle, listening, thinking, searching, working, bored, confused`). API `createAvatar` déjà 100% compatible avec l'usage contrôlé existant (`<Cubee animation={...} size={240} />`) — migration sans changement de comportement observable | Garder le code copié (statu quo) — écarté : maintenance manuelle d'un moteur dupliqué alors qu'une version maintenue par l'auteur existe désormais | actif  |

Licence inchangée : le package est aussi `AGPL-3.0-only` (vérifié sur le registry) → aucun impact sur la décision [BDR-001](BDR-001.md) de passer tout le repo Hooky en AGPL-3.0. Les en-têtes `NOTICE` par fichier disparaissent avec les fichiers copiés (plus pertinents pour une dépendance npm, qui porte son propre `LICENSE`).

Fichiers supprimés : `avatar-runtime.ts`, `Cubee.tsx`, `cubee.avatar.ts`, et le scaffold de démo Vite complet livré par le Studio (`cubee-avatar-react/`, dont seul le `.json` était utile). Nouveau `cubee.index.ts` réduit à 5 lignes (`createAvatar` + réexport du type `AnimationName` dérivé du JSON).
