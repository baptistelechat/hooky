# LRN-082 — Regarder comment des projets équivalents résolvent le même problème avant de dégrader l'UX

| Pattern observé                                                                                                                                                                                                                                                                                                                                                           | Contexte                                                                                                                      | Application future                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Face à un rate-limit sur l'endpoint usage, la première option envisagée (espacer le poll à 30-60min) dégradait la fraîcheur des données sans garantie de résoudre le problème. Chercher comment des projets équivalents (claude-pulse, ccstatusline) gèrent le même endpoint a révélé la vraie cause (retry sans backoff) et une solution qui garde l'intervalle de 3min. | Baptiste a explicitement rejeté la mitigation ("espacer à 30/60 min est absurde"), poussant à creuser plutôt qu'à contourner. | Avant de dégrader l'UX pour contourner une limitation externe (rate-limit, quota, latence), vérifier si des projets équivalents/OSS résolvent le même problème sans ce compromis -- souvent la vraie cause est ailleurs (ici : absence de backoff, pas la fréquence). |
