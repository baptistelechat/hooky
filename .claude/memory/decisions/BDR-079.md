# BDR-079 — SessionStart : chemin de hooky.exe lu dans le registre

| Décision                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                                                                                                                | Alternatives considérées                                                                                                                                                                                                                                                                                              | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le hook `SessionStart` (auto-launch) lit `InstallLocation` dans `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Hooky` via `powershell -NoProfile -Command "Start-Process (...)"`, au lieu du chemin en dur `%LOCALAPPDATA%\Hooky\Hooky.exe`. Snippet, README et CHANGELOG mis à jour. | Le `settings.json` est partagé entre deux postes dont les dossiers d'installation diffèrent (C: et D:) : une même ligne doit marcher partout, sans changement de code Rust. PowerShell ne démarre que si le `curl` échoue (app fermée). | Substitution par `std::env::current_exe()` dans `install_claude_hooks` (écartée : écrit un chemin propre à une machine dans un fichier partagé). `cmd` pur avec `reg query` + `for /f "tokens=2,*"` + `%~b` (testé et fonctionnel, écarté par Baptiste : il préfère PowerShell). Ne rien toucher et installer sur C:. | actif  |
