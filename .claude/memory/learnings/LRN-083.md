# LRN-083 — `claude auth status` ne rafraîchit pas le token OAuth

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                                                                                          | Application future                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une commande de "check" léger (`claude auth status`) ne déclenche pas les mêmes effets de bord qu'une opération complète (session interactive `claude` avec un vrai prompt) même quand elle semble faire la même vérification (`loggedIn`, `orgId`...). Vérifié en simulant un token `.credentials.json` expiré (backup/restore contrôlé) : `expiresAt` reste inchangé après `auth status`, alors qu'une vraie session `claude` rafraîchit bien un token réellement expiré depuis 3 jours. | Recherche d'un moyen "discret" de forcer un refresh du token OAuth Claude Code local depuis un outil tiers (Hooky, cf. [BDR-073](../decisions/BDR-073.md)) -- l'hypothèse initiale (`auth status` suffit) s'est avérée fausse, la seule preuve venait d'un test réel avant/après sur `expiresAt`. | Ne jamais supposer qu'une sous-commande "status/check/info" produit les mêmes effets de bord (ici : refresh réseau) qu'une opération complète du même outil -- vérifier empiriquement (comparer un état avant/après), même quand la commande semble légère et gratuite. |
