# LRN-095 — Tauri `asset:` : scope `allow_file` à l'exécution et CORS

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tauri v2, protocole `asset:` : (1) activer la feature Cargo `protocol-asset` ET `app.security.assetProtocol.enable: true` dans `tauri.conf.json` (`scope: []` suffit si le scope est rempli à l'exécution) ; (2) `app.asset_protocol_scope().allow_file(path)` autorise un fichier précis, échappe les motifs glob (`escaped_pattern`), enregistre aussi la forme sans préfixe `\\?\` sous Windows et est idempotent (`HashSet`) ; (3) `is_allowed` canonicalise le chemin demandé, donc un lien symbolique ne contourne pas le scope ; (4) la réponse porte `Access-Control-Allow-Origin` = origine de la fenêtre, donc `img.crossOrigin = 'anonymous'` devrait laisser lire les pixels d'un canvas. | Pets Codex : lu dans le source de `tauri 2.11.5` (`scope/fs.rs`, `protocol/asset.rs`). Points 1 à 3 confirmés en usage réel (les sprites s'affichent) ; le point 4 (canvas non « tainted » sur `asset:`) n'est pas encore confirmé dans l'app. | Servir des fichiers locaux de l'utilisateur au webview sans base64 : valider côté Rust puis `allow_file` au cas par cas ; `convertFileSrc(path, 'asset')` côté front, en retirant le préfixe `\\?\` d'un chemin canonique. Vérifier le point 4 avant de s'appuyer sur la lecture de pixels. |
