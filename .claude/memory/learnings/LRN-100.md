# LRN-100 — Suivre le curseur hors fenêtre Tauri : polling de cursorPosition

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Pour réagir à un curseur qui dépasse la fenêtre : `cursorPosition()` (position globale, px physiques) + `getCurrentWindow().outerPosition()`, convertis en px logiques par `devicePixelRatio`, comparés au centre de l'élément (`getBoundingClientRect`). La permission `core:window:allow-cursor-position` est déjà dans `core:default` (lecture seule). Garde `busy` contre le chevauchement des lectures IPC. | Pet Hooky : le rayon de réveil (260 px) dépasse la fenêtre 240×240, et `setIgnoreCursorEvents` n'est pas fiable sur Windows, donc les événements souris de la fenêtre ne conviennent pas. | Polling (~100 ms) uniquement tant que le comportement est actif, arrêté au démontage. Vérifier la permission dans `gen/schemas/acl-manifests.json` (ex. `allow-cursor-position` dans le set par défaut de `core:window`) avant d'ajouter une capability. Non testé multi-écrans / mise à l'échelle ≠ 100 %. |
