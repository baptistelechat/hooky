# LRN-118 — shadcn add : import `cn` cassé + dépendance npm parasite

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Contexte                                                | Application future                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm dlx shadcn@latest add select` puis `add accordion` (style `base-nova`) ont généré `import { cn } from "cn"` et **ajouté la dépendance npm `cn`** à `package.json` et au lockfile, au lieu de `@/lib/utils`. Le composant ne compile pas correctement avec le mauvais paquet. À corriger après **chaque** `add` : remplacer l'import par `@/lib/utils`, puis `git checkout -- package.json pnpm-lock.yaml` (ces deux fichiers étaient propres avant). Vu deux fois dans la session. | Ajout du select (feels) puis de l'accordéon (réglages). | Après tout `shadcn add` : `git status package.json pnpm-lock.yaml` et `grep 'from "cn"' src/components/ui`. Voir aussi LRN-105 (autre défaut du CLI, `registryDependencies`). |
