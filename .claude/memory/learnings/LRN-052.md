# LRN-052 — Tailwind ne génère que des classes littérales, jamais construites par interpolation

| Pattern observé                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tailwind ne génère du CSS que pour les classes dont la chaîne complète apparaît littéralement dans le code source scanné — une classe construite par interpolation de variable (ex: `` `outline-${color}-500` ``) n'est jamais détectée ni générée, sans erreur ni avertissement (purge silencieuse). | Conception de `debugZoneClass()` (`src/lib/debugZone.ts`, helper de coloration des zones de debug, cf. [BDR-042](../decisions/BDR-042.md)) : évité dès la conception en écrivant un object map de chaînes complètes et littérales par zone (`ZONE_COLORS`), sélectionnées par clé plutôt que composées dynamiquement. | Sur tout projet Tailwind, toujours écrire les classes candidates comme des chaînes littérales complètes quelque part dans le fichier scanné (switch/objet de constantes), jamais construites par concaténation/interpolation d'une variable dans le nom de la classe. |
