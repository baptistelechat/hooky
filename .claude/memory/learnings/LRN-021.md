# LRN-021 — lucide-animated est un registre copier-coller, pas un package npm

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                        | Application future                                                                                                                                                                                                                                                                                |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chaque icône de [lucide-animated.com](https://lucide-animated.com) (`pqoqubbw/icons` sur GitHub) s'installe via `npx shadcn add <url>` et devient un fichier possédé dans le repo (composant Motion avec `startAnimation`/`stopAnimation` exposés par ref), pas un import depuis un package. Comportement par défaut : animation single-shot déclenchée au survol (hover) ; pas de boucle continue native — il faut éditer chaque fichier copié (ajouter `repeat: Infinity` + un auto-démarrage `useEffect` au montage) pour obtenir une boucle. La couverture n'est pas 1:1 avec `lucide-react` : certaines icônes (`TriangleAlert`, `Ear`, `MessageCircleQuestion`, `PauseCircle`, `HelpCircle` exact) n'ont pas d'équivalent animé exact, nécessitant des substituts sémantiquement proches. | Remplacement des 12 icônes de badge de Hooky par des versions animées (cf. [BDR-023](../decisions/BDR-023.md)). | Avant de choisir cette lib pour un besoin d'icônes animées, prévoir : la dépendance `motion` ajoutée au bundle, les fichiers à maintenir à la main (pas de mise à jour amont automatique), le travail de conversion single-shot→boucle, et un mapping de substitution pour les icônes manquantes. |
