# BDR-016 — Effets visuels du pet via Web Animations API native

| Décision                                                                                                                                                                                                       | Pourquoi                                                                                                                                                                                                                                                                                                               | Alternatives considérées                                                                                                                                                                                                                               | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Confettis, bounce (celebrate), shake (confused) et fade du badge implémentés via `Element.animate()` (WAAPI, hook partagé `useWaapi`), pas via classes Tailwind `animate-*` ni fichier CSS de keyframes dédié. | Le projet bannit les fichiers CSS custom (cf. décision antérieure resets globaux) — WAAPI est une API DOM native, zéro dépendance, permet de rejouer un effet ponctuel à la demande (`revision` en dépendance) sans dépendre d'une classe CSS statique ni d'un montage/démontage React pour déclencher une transition. | Tailwind `animate-*`/`tw-animate-css` (déjà en dépendance) : ne permet pas de rejouer un effet ponctuel facilement sans jouer sur les clés React ; keyframes CSS dans un fichier dédié : contredit la convention "pas de fichier CSS custom" du projet | actif  |
