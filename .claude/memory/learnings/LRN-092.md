# LRN-092 — Couleur dominante : regrouper par plage de teinte

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                      | Contexte                                                                                                                                                                                                                          | Application future                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour la couleur dominante d'une illustration ombrée, regrouper les pixels par plage de teinte (ex. 12 plages de 30°) et non par couleur exacte : l'ombrage éparpille un même aplat en dizaines de nuances proches, chacune trop rare. Mesuré sur `work-blue-cat` : le vert du t-shirt pesait 2 % en groupes RGB de 4 bits, 8 % par plage de teinte, alors que le gris du contour (15 %) l'emportait. | Badge des pets Codex : la première version (couleur exacte la plus fréquente) retombait sur le gris, exactement le défaut à corriger. Détecté en portant l'algorithme en Python (Pillow) sur les vrais pixels avant de le livrer. | Filtrer d'abord les pixels « de caractère » (saturation ≥ 0,25, luminosité 0,15–0,9), les compter par plage de teinte, exiger une part minimale (ici 3 %) sinon retomber sur la couleur la plus fréquente, puis garantir le contraste (`ensureReadableOnWhite`). Tester sur des pixels réels, pas sur un exemple imaginé. Voir aussi GLRN-186 (auto-ajustement WCAG). |
