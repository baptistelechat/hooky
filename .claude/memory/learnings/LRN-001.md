# LRN-001 — Liseré blanc sur fenêtre undecorated = shadow natif Windows

**Pattern observé** : Windows applique par défaut une ombre native (coins arrondis + liseré 1px) aux fenêtres Tauri `decorations: false`, indépendamment de la taille de la fenêtre

**Contexte** : Bordure/liseré blanc persistant autour de l'avatar Cubee. Fausse piste initiale : marge de fenêtre (300×300) — le problème persistait même à cette taille

**Application future** : Sur toute fenêtre Tauri transparente/undecorated Windows, vérifier `"shadow": false` dans `tauri.conf.json` avant de chercher une cause côté marge/padding CSS

Fix appliqué : `"shadow": false` + fenêtre repassée à 240×240 exact (0 marge). Vérifié visuellement en zoomant sur le rendu — fond fondu directement dans le bureau.
