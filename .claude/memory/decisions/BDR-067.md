# BDR-067 — Bump de version unifié : `pnpm release:*` synchronise tous les fichiers

| Décision                                                                                                                                                                                                                                                                                           | Pourquoi                                                                                                                                                                                                                                                                                       | Alternatives considérées                                                                                                                                                                                                                       | Statut |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `pnpm release:patch\|minor\|major` (= `pnpm version <bump>`) + hook `"version"` (`scripts/sync-version.mjs`) qui synchronise `src-tauri/tauri.conf.json` et `src-tauri/Cargo.toml`/`Cargo.lock` sur la version bumpée de `package.json`, avant que `pnpm version` ne commit + tag automatiquement. | Trois fichiers portent la version (`package.json`, `tauri.conf.json`, `Cargo.toml`) sans lien entre eux -- risque réel de désync à chaque release. Le premier tag (`v0.1.0`) a d'ailleurs été poussé sans tag créé du tout au départ (oubli), d'où le besoin d'automatiser aussi cette partie. | Script one-off manuel à chaque release (rejeté : c'est exactement l'oubli récurrent qu'on veut éliminer) ; outil tiers de version bump type `standard-version` (rejeté : `pnpm version` natif + un hook suffisent, pas de dépendance de plus). | actif  |
