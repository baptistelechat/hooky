# LRN-019 — Composant SVG dans un `<div>` wrapper ignore la classe de taille

| Pattern observé                                                                                                                                                                                                                                                                                                                                              | Contexte                                                                                                                                                                                       | Application future                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un composant icône qui rend son `<svg>` à l'intérieur d'un `<div className={cn(className)}>` wrapper (cas de tous les composants lucide-animated) ignore une classe de taille Tailwind (`size-3`) passée en `className` : celle-ci ne stylise que le `<div>`, le `<svg>` interne garde son propre attribut `width`/`height` (valeur par défaut, souvent 28). | `AnimationCard.tsx` (grille de validation des settings) affichait des badges d'icône énormes, tronquant les libellés voisins ("rking" au lieu de "working", "arching" au lieu de "searching"). | Toujours passer explicitement `size` en prop numérique à ce type de composant plutôt que de compter sur une classe CSS de taille — vérifier où atterrit vraiment `className` (wrapper ou élément stylisable) avant de l'utiliser pour dimensionner. |
