# BDR-018 — Highlight de l'onglet Animation basé sur le clic local, pas l'agrégat live

| Décision                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                        | Alternatives considérées                                                                                                                                                                                                                                                                                                 | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| La carte "en cours" dans la grille de validation (`AnimationValidation`) est surlignée via un état purement local (`selectedLabel`, mis à jour au clic sur une carte), pas via `useHookyState()` (l'agrégat live multi-session diffusé par le backend). | Le pet réel agrège TOUTES les sessions Claude Code actives par priorité (`working` > `searching` > ...) : une session réelle active en parallèle du test dominait l'agrégat et faisait apparaître un highlight sans rapport avec le clic, ou plusieurs cartes en même temps quand plusieurs hooks partageaient l'animation dominante. Un état local découplé élimine complètement cette course. | Highlight basé sur `useHookyState()` avec toutes les cartes partageant la même animation (essayé en premier, rejeté par retour utilisateur répété : "tu allumes tout ceux qui ont la même animation") ; highlight basé sur l'agrégat mais une seule carte (essayé, toujours pollué par les vraies sessions concurrentes) | actif  |
