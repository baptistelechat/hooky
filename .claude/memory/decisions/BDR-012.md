# BDR-012 — Grille de validation visuelle des animations dans les settings

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                                                                                                                                                                     | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Nouvel onglet "Animation" dans la fenêtre settings : chaque hook Claude Code et chaque `notification_type` rejoue en boucle sa propre instance `AvatarEngine` contrôlée localement (`useState` par carte, indépendante de `hooky-state`), grille CSS `grid-cols-[repeat(auto-fill,minmax(150px,1fr))]` (pas de breakpoints Tailwind manuels, pas de dépendance Tabs shadcn), fenêtre plafonnée à 620px de large (Tauri `maxWidth`/`maxHeight`) pour garder la grille à 3 colonnes max, `Settings.tsx` restructuré en dossier `Settings/index.tsx` + `components/` (seuil des 200 lignes dépassé) | Le mapping event→animation (`docs/EVENTS.md`) avait été décidé par sémantique, jamais confronté au rendu réel du moteur `@bible-strong/avatar-react`. Demande explicite de Baptiste : valider si l'animation montre réellement ce que son nom promet, pas juste s'y fier | Rejouer les animations dans la fenêtre du pet réelle en forçant un état (rejeté : aucun mécanisme de forçage manuel existant, aurait pollué le flux `hooky-state` réel) ; lecteur de "transitions" avec presets et délai configurable (ajouté puis retiré à la demande de Baptiste après un premier retour, jugé hors scope) | actif  |
