# LRN-020 — Transition CSS d'entrée sur nœud fraîchement monté = double rAF

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                            | Contexte                                                                                                                                                                                                                                                  | Application future                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Un élément qui naît dans le même rendu à `opacity-0` puis passe à `opacity-100` via un seul `requestAnimationFrame` peut ne jamais animer : le navigateur peut coalescer les deux changements de classe dans la même frame car aucun paint n'a eu lieu entre les deux — l'élément apparaît instantanément à son état final. Un double `requestAnimationFrame` imbriqué force un paint intermédiaire avant de basculer vers l'état visible. | Le badge d'icône de Hooky (React + Tailwind transitions) animait bien sa disparition (transition sur un nœud déjà existant, avec un vrai avant/après connu du navigateur) mais pas son apparition (nouveau nœud monté directement dans son état visible). | Pour toute animation d'entrée CSS sur un élément conditionnellement monté en React, séparer l'état "monté" (présence DOM) de l'état "visible" (classes d'opacité/scale) — ce dernier basculé après un double rAF, jamais dans le même rendu que le montage. |
