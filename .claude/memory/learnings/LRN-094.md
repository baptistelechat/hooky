# LRN-094 — Doc web illisible : lire le tarball npm de la CLI

| Pattern observé                                                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                                                                                                                    | Application future                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Quand la doc web d'un outil est illisible pour `WebFetch` (page rendue côté client), `npm pack <paquet>` télécharge le tarball de sa CLI : son README et son AGENTS.md sont lisibles en clair et donnent les chemins et règles réels ; le JS minifié se sonde avec un `grep -o -E '.{150}motif.{150}'` ciblé plutôt qu'un `grep -n` (tout tient sur une ligne géante). | Chemin d'installation de `npx petdex install` : le README de `petdex@1.3.0` a révélé qu'il écrit dans `~/.petdex/pets` et `~/.codex/pets`, ainsi que le format v2 8×11 ; `CODEX_HOME` n'apparaît nulle part dans le bundle. | Pour toute CLI npm dont on doit connaître le comportement (dossiers, formats, variables d'environnement) : `npm pack` dans le scratchpad, `tar -xzf`, lire README/AGENTS.md d'abord, puis chercher les motifs précis dans `dist/`. L'absence d'un motif dans un bundle minifié est un indice fort, pas une preuve. |
