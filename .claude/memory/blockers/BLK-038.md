# BLK-038 — Config Vite ignorée : serveur orphelin sur le port 1420

| Friction                                                                                                                                                                                                                                                                            | Cause réelle                                                                                                                                                                                                                                                                                                                                                                                                                | Solution                                                                                                                                                                                                                                                                                                      | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Après l'ajout du plugin `unplugin-typegpu` dans `vite.config.ts`, l'erreur `Missing metadata for tgpu.fn function body` persistait à chaque redémarrage de `tauri dev` ; on a d'abord soupçonné le plugin lui-même. Par ailleurs, le build de dev s'arrêtait aussitôt au lancement. | Deux causes cumulées : (1) `taskkill hooky.exe` ne tue pas Vite, et `tauri dev` réutilise le serveur déjà présent sur `:1420` (ancienne config, `strictPort` ne change rien) ; (2) l'instance installée de Hooky (`AppData\Local\Hooky`) détient le port 4242 et le plugin single-instance, donc le build de dev quitte immédiatement. Le plugin, lui, fonctionnait (transform vérifié en isolation puis via `pnpm build`). | Fermer l'instance installée (avec accord), tuer le process qui écoute sur `:1420` (`netstat -ano \| grep :1420`, puis `taskkill /F /PID <pid> /T`), relancer `tauri dev`, puis vérifier que le fichier servi contient bien la transformation avant de conclure. Relancer l'instance installée en fin de test. | résolu |
