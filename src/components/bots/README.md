# Open Bot Avatar

Avatars de la galerie d'[Open Bot Avatar](https://github.com/DominikScholz/open-bot-avatar) (Dominik Scholz), copiés tels quels depuis son dossier `gallery/` : un fichier `<id>.json` par avatar, et `colors.json` pour la couleur par défaut de chacun. Les 7 avatars de départ (controller, mug...) viennent du package npm `open-bot-avatar` lui-même.

Licence : MIT, Copyright (c) 2026 Dominik Scholz — voir <https://github.com/DominikScholz/open-bot-avatar/blob/main/LICENSE>.

Déposer un nouveau JSON au même format ici suffit à l'ajouter au picker (couleur par défaut à renseigner dans `colors.json`).
