# BDR-070 — Intervalle de poll usage conservé à 3min, pas de passage à 1min

**Décision** : `USAGE_POLL_INTERVAL` (spawn_usage_poller, src-tauri/src/lib.rs) reste à 180s

**Pourquoi** : L'endpoint `api/oauth/usage` a un historique documenté de rate-limit agressif (issues GitHub `anthropics/claude-code`) ; le poll unique côté backend déjà en place corrigeait un rate-limit constaté quand chaque survol de l'avatar déclenchait son propre appel. Le quota bouge lentement à l'échelle d'une session de travail : pas de vrai gain d'usage à raccourcir

**Alternatives considérées** : Passer à 60s (proposé par Baptiste, écarté après argumentation sur le risque de 429)
