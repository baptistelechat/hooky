# LRN-056 — État dérivé pilotant rendu ET clamp externe : geler pendant l'interaction, valider au relâchement

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                                                                                                                  | Application future                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand un état dérivé (ex. `flipped`, calculé depuis la position de fenêtre) pilote À LA FOIS le rendu visuel ET un calcul externe (clamp de drag), le laisser se recalculer EN CONTINU pendant une interaction utilisateur (drag) crée deux risques distincts : (1) l'état change en plein geste, désynchronisant l'objet manipulé du curseur ; (2) si l'état change PILE au moment du relâchement, le calcul externe (fait pour l'ANCIENNE valeur) peut devenir invalide pour la NOUVELLE, sans qu'aucun code ne le corrige. | `flipped` (Hooky) -- gelé pendant un drag (`freezeFlip`), commité au relâchement (`commitFlip`, qui RETOURNE la nouvelle valeur), et le code de clamp compare cette valeur retournée à celle utilisée pendant le drag pour re-clamper si elles diffèrent. | Pour un état dérivé de ce type, exposer explicitement 3 primitives -- geler (freeze), lire la DERNIÈRE valeur réelle même gelée (pour un commit immédiat sans attendre un nouvel event), et commiter en RETOURNANT la nouvelle valeur (pour que le code dépendant externe puisse réagir au changement, pas seulement au state React). |
