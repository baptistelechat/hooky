# BDR-005 — Avatar fusionné dans `src/components/` avec noms génériques pour swap à chaud du JSON

**Décision** : Supprimer `src/avatar/` ; déplacer `cubee.avatar.json` → `src/components/avatar.json` et fusionner le barrel dans `src/components/Avatar.tsx` (composant public `PetAvatar`, moteur interne renommé `AvatarEngine`)

**Pourquoi** : Après la migration vers le package npm ([BDR-004](BDR-004.md)), il ne restait qu'un fichier de données + un barrel de 5 lignes dans `src/avatar/` — plus de raison de garder un dossier séparé. Noms génériques (`avatar.json`, pas `cubee.avatar.json`) : Baptiste veut pouvoir tester un autre export du Studio bible-strong en écrasant juste le JSON, sans renommer de code

**Alternatives considérées** : Garder `src/avatar/` séparé avec un `Avatar.ts` dédié — écarté après question de Baptiste : un fichier séparé pour 5 lignes n'est plus justifié une fois le moteur externalisé en dépendance npm
