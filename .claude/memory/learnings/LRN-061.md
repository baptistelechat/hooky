# LRN-061 — `GetWindowRgn` est déclarée dans `user32.dll`, pas `gdi32.dll`

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                       | Contexte                                                                                                                                                                                                                                                 | Application future                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Contrairement à `CreateRectRgn`/`PtInRegion`/`SetWindowRgn` (toutes dans `gdi32.dll`, cohérent avec le reste de l'API GDI de gestion des régions), `GetWindowRgn` est en réalité exportée par `user32.dll` -- un P/Invoke déclarant `[DllImport("gdi32.dll")]` pour `GetWindowRgn` échoue avec `Unable to find an entry point named 'GetWindowRgn' in DLL 'gdi32.dll'`, malgré le nom cohérent avec ses voisines GDI. | Script PowerShell de vérification (interop Win32) de la région appliquée par `SetWindowRgn` sur la fenêtre Hooky -- déclaration groupée par "logique de nommage" (toutes les fonctions de région dans `gdi32.dll`) plutôt que vérifiée individuellement. | Ne jamais assumer la DLL d'une fonction Win32 par analogie avec des fonctions au nom proche -- vérifier chacune individuellement (docs.rs pour le crate `windows`, ou learn.microsoft.com) avant de grouper des `DllImport`. |
