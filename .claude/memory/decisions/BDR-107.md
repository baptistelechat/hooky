# BDR-107 — Dots Lab : planche SVG brute comme format unique

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                                                                                                                                                          | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Les personnages Dots Lab sont un troisième type d'avatar (`kind: "dots"`, à côté de `procedural` et `sprite`). Un personnage = un fichier `src/components/dots/<nom>.svg`, la planche « Copy SVG sheet » (8 états, style Animated) enregistrée telle quelle. `splitDotsSheet` (`src/lib/dotsAvatars.ts`) la découpe à l'exécution en 8 SVG autonomes, affichés un par un dans un `<img>` via des URLs `blob:` (`useDotsSheet`). Les planches sont chargées en `?url`, pas en `?raw`. | Baptiste a corrigé ma première proposition : l'utilisateur de Dots Lab obtient une planche SVG, pas un JSON, donc le format livré et le futur format d'import doivent être cette planche. Déposer un fichier suffit à ajouter un personnage, comme pour `./avatars/*.json`. Le découpage évite de faire tourner 7 animations cachées ; `?url` garde 7 Mo de SVG hors du bundle JS ; un `<img>` joue l'animation SMIL sans exécuter de script, ce qui servira pour l'import de fichiers tiers. | Un JSON par personnage contenant les 8 SVG (écarté : ce n'est pas ce que l'outil exporte). 96 fichiers pré-découpés par un script (écarté : ajout d'un personnage non trivial, logique de découpe dupliquée avec l'import). Afficher la planche entière recadrée sur une case (écarté : les 8 animations tournent en permanence). | actif  |

## Notes

- Intégration commitée en WIP (`3f21e6c`) : lint et build verts, découpage vérifié sur les 12 planches dans un navigateur, mais rendu dans l'app Tauri non validé.
- Points à trancher à l'usage : pastille propre aux états Alert/Error/Thinking/Asleep qui peut chevaucher le badge de Hooky ; `waking` mappé sur Alert ; ~1 s cumulée de découpage à l'ouverture du picker.
- Import utilisateur (coller ou choisir une planche) non fait.
