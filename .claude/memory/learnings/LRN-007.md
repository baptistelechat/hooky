# LRN-007 — Une liste de priorité d'agrégation doit couvrir tout l'espace de sortie du mapping

| Pattern observé                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `resolve_state()` s'appuyait sur `STATE_PRIORITY`, une liste de priorité qui ne listait pas toutes les animations que `animation_for_event()` peut produire (`waking`, `confused` absentes) → une session dans un de ces états retombait silencieusement sur `bored` en agrégat, sans erreur ni log | Découvert en vérifiant pourquoi une session tout juste démarrée (`SessionStart` → `waking`) ne s'affichait pas comme attendu dans l'état agrégé | Toute fonction qui agrège/priorise un ensemble fermé de valeurs (`match`, liste de priorité) doit être auditée à chaque ajout d'une nouvelle valeur possible côté source — un test qui vérifie que `STATE_PRIORITY` couvre bien toutes les valeurs de `animation_for_event()` éviterait la classe de bug |
