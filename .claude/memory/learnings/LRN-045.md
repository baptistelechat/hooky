# LRN-045 — Restreindre un `mousedown` délégué via data-attribute + `closest()`, pas `pointer-events`

| Pattern observé                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Application future                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour limiter une action déclenchée par un handler `mousedown` posé sur un large conteneur (ex : drag de fenêtre undecorated) à des éléments précis, marquer ces éléments d'un attribut (`data-drag-handle`) et faire `e.target.closest("[data-drag-handle]")` dans le handler délégué, sans toucher à `pointer-events`. | Fenêtre Tauri du pet Hooky : le drag sur `mousedown` couvrait toute la fenêtre et se déclenchait aussi depuis des zones transparentes vides. Une tentative précédente ([BDR-038](../decisions/BDR-038.md)) avait essayé de restreindre via `pointer-events` (SVG `visiblePainted`) pour permettre du click-through vers l'app derrière — abandonnée car `setIgnoreCursorEvents` non fiable sur Windows/WebView2. Objectif différent cette fois (juste ignorer le mousedown sur du vide, pas de click-through) : l'écueil précédent ne s'applique pas. | Pour restreindre la zone de capture d'un event délégué (drag de fenêtre, zone cliquable custom...) sans besoin de click-through, préférer un hit-test JS (data-attribute + `closest()`) à une manipulation de `pointer-events` — plus robuste (n'hérite pas dans le SVG, cf. [LRN-041](LRN-041.md)) et sans risque de casser un mécanisme `pointer-events` déjà en place ailleurs sur la page. |
