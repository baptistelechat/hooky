# LRN-006 — Convention à portée large appliquée sans confirmer le périmètre exact = sur-scope

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                   | Contexte                                                                                                                                                                        | Application future                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une consigne du type "bannir X" / "tout migrer vers Y" appliquée littéralement à l'ensemble d'un diff peut sur-scoper le refactor au-delà de ce que l'utilisateur voulait réellement. Ici : migrer 3 classes composant vers Tailwind a entraîné, par extension non voulue, le déplacement des resets globaux `html`/`body`/`#root` hors d'un fichier CSS dédié vers `index.html`. | Session Hooky, migration `App.css` → Tailwind ([ZBDR-008](../archive/decisions/ZBDR-008.md)), partiellement revert le lendemain ([ZBDR-009](../archive/decisions/ZBDR-009.md)). | Sur toute consigne de convention à portée large touchant un fichier avec plusieurs blocs distincts (ex: resets globaux vs styles de composant), appliquer chaque bloc à son mérite plutôt que par réflexe d'exhaustivité — signaler le périmètre envisagé avant d'exécuter si le diff touche des zones au comportement différent. |
