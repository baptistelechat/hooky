# BLK-034 — Navigateur intégré : origines locales refusées

| Friction                                                                                                                                                                                            | Cause réelle                                                                                                                                                                                                                                                                   | Solution                                                                                                                                                                                                                                       | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Le navigateur intégré (`navigate`) a refusé `localhost:1420`, `127.0.0.1:1420`, `127.0.0.1:8766` puis `127.0.0.1:8765`, alors que `127.0.0.1:8765` avait été accepté plus tôt dans la même session. | Non établie. Hypothèse non vérifiée : la fermeture du dernier onglet (`tabs_close`) a fermé le pane, et l'autorisation d'origine accordée à sa première ouverture n'a pas survécu à la réouverture. À rapprocher de GLRN-288 (autre blocage du même pane : domaines externes). Constat de la session 3 : un pane rouvert d'emblée sur `127.0.0.1:8765` a été accepté (page de test canvas, [LRN-097](../learnings/LRN-097.md)), donc le refus n'est pas permanent ; la fermeture du dernier onglet n'avait pas été retentée. | Contournement, pas une correction : plus d'essais de navigation ; logique testée dans Node ([LRN-096](../learnings/LRN-096.md)) et couleur prédite par un portage Python. À retester : ne pas fermer le dernier onglet entre deux essais, ou rouvrir via `preview_start`. | ouvert |
