# LRN-063 — `Tauri::Window::hwnd()` doit être réenveloppé pour la crate `windows`

| Pattern observé                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                                                                                                                                                                         | Application future                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Window::hwnd()` (Tauri v2, Windows) retourne son propre type wrapper -- pas directement compatible avec les fonctions Win32 de la crate `windows` (`SetWindowRgn`, etc.), qui attendent `windows::Win32::Foundation::HWND`. Il faut extraire le pointeur brut (`.0`) du wrapper Tauri puis le réenvelopper : `let hwnd = HWND(window.hwnd()?.0);`. | Commande Rust `apply_window_shape` (Hooky, `src-tauri/src/lib.rs`) appelant `SetWindowRgn` sur la fenêtre "main" -- pattern confirmé fonctionnel après `cargo check`, cohérent avec un exemple externe trouvé en recherche (tauri-windows-clickthrough-example). | Pour tout appel Win32 natif (crate `windows`) sur un handle de fenêtre Tauri, toujours extraire `.0` du retour de `.hwnd()` avant de le passer à une fonction de la crate `windows` -- ne jamais supposer une conversion `Into`/`From` implicite entre les deux types. |
