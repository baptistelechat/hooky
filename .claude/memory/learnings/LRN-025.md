# LRN-025 — `ListAgents`/`SendMessage` pour interroger une autre session Claude Code active plutôt que deviner

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                     | Application future                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pour diagnostiquer si une AUTRE session Claude Code active sur la machine (loop, cron, sous-agent en arrière-plan) était la source d'un comportement observé, `ListAgents` a permis de lister les sessions locales réellement actives, puis `SendMessage` d'interroger directement la session suspecte (ses propres `/loop`, `CronList`, sous-agents) — réponse vérifiable en quelques secondes au lieu d'une hypothèse | Debug de Hooky (serveur local agrégeant les hooks de toutes les sessions Claude Code de la machine) ; besoin de savoir si une session idle spécifique avait un mécanisme d'auto-réveil actif | Face à un comportement suspecté d'impliquer une autre session/processus Claude Code sur la même machine, utiliser `ListAgents` pour identifier les sessions candidates puis `SendMessage` pour leur demander directement leur état (loops, crons, subagents) plutôt que de spéculer depuis l'extérieur — un cross-check direct bat une inférence indirecte |
