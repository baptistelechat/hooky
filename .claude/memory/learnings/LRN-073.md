# LRN-073 — `@tailwindcss/vite` scanne tout le repo par défaut, exclure explicitement la doc du watch

| Pattern observé                                                                                                                                                                                                                                                                                              | Contexte                                                                                                                                                                                                                                                                                                                               | Application future                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@tailwindcss/vite` (Tailwind v4) scanne tout le répertoire du projet par défaut pour détecter les classes utilisées -- éditer un fichier hors du graphe de modules (`README.md`, `docs/**`) déclenche quand même un full-reload CSS de la fenêtre webview, alors qu'aucun module React/CSS réel n'a changé. | Éditer `README.md`/`docs/RELEASE.md` pendant que l'app Tauri tournait en dev faisait disparaître/clignoter l'avatar dans la fenêtre "main", sans lien apparent avec le contenu du fichier touché -- diagnostiqué en confirmant que `vite.config.ts` ne watchait que `src-tauri`/`.claude` en exclusion, laissant `docs/**` non filtré. | Dans tout projet Vite + `@tailwindcss/vite`, exclure explicitement de `server.watch.ignored` les répertoires purement documentaires (`docs/**`, `README*.md`) -- même logique que l'exclusion déjà en place pour `src-tauri`/`.claude` sur ce projet. Le fix ne prend effet qu'au prochain démarrage du serveur Vite (`server.watch` n'est lu qu'au démarrage). |
