# BDR-098 — Pack uisfx copié dans le repo, 12 feels au choix

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Pourquoi                                                                                                                                                                                                                                                      | Alternatives considérées                                                                                                                                                                                                                      | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Utiliser le pack **uisfx** 0.4.0 (audio CC0, code MIT) en **copiant** dans `src/assets/sounds/<feel>/` uniquement les 15 cues MP3 et la boucle OGG utilisés, pour chacun des 12 feels (≈ 2 Mo), avec `LICENSE-AUDIO` et un `README.md` de provenance, sans dépendance npm. Réglage `soundFeel` : select avec la couleur de marque et la description de chaque feel (issues du `manifest.json` du paquet, descriptions traduites par moi), défaut **Minimal**, aperçu du cue `complete` à chaque choix. | La licence CC0 autorise la redistribution dans un repo AGPL public sans attribution. Des fichiers statiques cadrent avec `new Audio(url)` déjà en place. Changer de feel = changer de dossier, le mapping ne bouge pas : ça personnalise le caractère du pet. | Cuelume (17 cues synthétisés Web Audio, MIT : moins riche, dépend d'un `AudioContext` sans geste utilisateur) ; le runtime `uisfx` en dépendance npm (synthèse à la volée, remplace les fichiers, ajoute une dépendance) ; un seul feel figé. | actif  |
