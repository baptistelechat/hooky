# BDR-094 — Orbs abandonnés, retirés à la main (sans revert)

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Alternatives considérées                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Les orbs (spike shadercn / WebGPU) sont abandonnés pour le moment. Leur code est retiré **à la main** par un nouveau commit de suppression (`47b7f65`, gitmoji 🔥), pas par `git revert` ni par réécriture de l'historique : le spike (`9fde588`) et sa mémoire (`76b7850`) restent consultables. Le retour à l'état de la v0.3.0 est prouvé par `git diff 884a9d2 --stat` vide sur `package.json`, `pnpm-lock.yaml`, `src/`, `vite.config.ts` et `vite.config.js`. | Baptiste arrête le chantier orbs (licence non-commerciale de XorDev toujours non tranchée, cf. [BDR-093](../decisions/BDR-093.md)) sans vouloir perdre la trace du spike. Il a explicitement refusé le `git revert` (« je veux que tu clean le code ») et rappelé que réécrire l'historique est destructif pour le projet. Le nettoyage manuel donne le même résultat, avec un contrôle fichier par fichier (`pnpm remove` pour les 4 dépendances, `git rm` pour le dossier). | (A) `git revert 9fde588` : essayé en premier (`--no-commit`), écarté par Baptiste ; (B) `git reset` / `rebase` pour effacer le spike de l'historique : destructif, écarté ; (C) garder les orbs derrière `SPIKE_ORB = false` : laisse ~1 300 lignes, 4 dépendances et un plugin Vite inutilisés ; (D) reprendre plus tard la piste licence (accord de XorDev, shaders maison, orbs installés par l'utilisateur) : reste ouverte dans [BDR-093](../decisions/BDR-093.md), non engagée. | actif  |
