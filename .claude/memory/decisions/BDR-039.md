# BDR-039 — Son SessionStart porté (`start.wav`), notify.ps1 totalement retiré

**Décision** : Port de `start.wav` dans `src/assets/sounds/`, joué sans bulle dans `NotificationBubble` dès que `lastEvent === "SessionStart"`. Suppression du dernier appel `Send-ClaudeNotification` (notify.ps1) restant dans `hooks/session-start-context.ps1`, qui jouait encore ce son en direct — indépendamment de `main.ps1`, dont le switch `$sound` ne gérait déjà pas `'Start'`.

**Pourquoi** : Complète le remplacement de notify.ps1 par Hooky entamé par [BDR-036](../decisions/BDR-036.md) (qui n'avait couvert que `Stop`/`Notification`) — sans ce retrait, le son de démarrage aurait joué deux fois (notify.ps1 + Hooky).

**Alternatives considérées** : Porter aussi la bulle de texte (pool `Start` de `messages.ps1`) — écarté, hors périmètre demandé (son seul).
