# BDR-042 — Zones du mode debug en classes Tailwind, une couleur par zone, bulle/badge sans fond

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                             | Alternatives considérées                                                                                                                                                                                                                                                                                         | Statut |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Visualisation des zones de la fenêtre "main" (mode debug) via un helper Tailwind (`debugZoneClass()`, `src/lib/debugZone.ts`) plutôt que du CSS custom dans `index.css` : contour + étiquette (`before:content-[attr(data-zone)]`), une couleur distincte par zone (window=rouge, slot=bleu, avatar=vert, bubble-zone=jaune, bubble=violet, badge=rose). Fond teinté uniquement sur les zones de layout invisibles (window/slot/bubble-zone/avatar) — `bubble` et `badge` sont de vrais éléments visibles (bulle blanche, badge blanc) dont l'apparence ne doit pas changer en debug, contour seul. | Cohérent avec la convention déjà actée du projet (tout en Tailwind/className, cf. [BDR-014](BDR-014.md)) — signalé explicitement par Baptiste après une première version en CSS brut. Une couleur par zone (plutôt qu'un binaire draguable/mort) permet d'identifier chaque zone d'un coup d'œil. Garder bulle/badge blancs évite de fausser leur rendu réel pendant qu'on debugge le layout autour. | CSS brut via `[data-debug] [data-zone]` dans `index.css` — écarté, cause racine du bug de positionnement (cf. [LRN-050](../learnings/LRN-050.md)) et contraire à la convention Tailwind du projet. Fond teinté partout y compris bulle/badge — écarté sur demande explicite de Baptiste (doivent rester blancs). | actif  |
