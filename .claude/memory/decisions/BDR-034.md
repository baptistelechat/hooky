# BDR-034 — Boutons reset dupliqués (`ResetButtons`) plutôt que déplacés

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Alternatives considérées                                                                                                                                                                                                                                                                             | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Les boutons "Réinitialiser Cubee"/"Réinitialiser les avatars" sont rendus deux fois via un composant partagé `ResetButtons` (props identiques, `className` différent) : une instance imbriquée dans `FieldContent` (visible seulement à `@md/field-group`, sous la description), une instance dans un `Field` séparé (visible seulement en dessous de `@md/field-group`, layout étroit inchangé). Les deux `AlertDialog` de confirmation restent uniques, contrôlés en state, sans `AlertDialogTrigger` -- les boutons appellent directement `setOpen(true)`. | Baptiste voulait les boutons sous la description en fenêtre large (nouveau layout) sans changer le rendu en fenêtre étroite (existant, validé). Ces deux positions appartiennent à deux conteneurs flex différents (l'un imbriqué dans `FieldContent`, l'autre sibling du `Field` principal) -- `order` CSS ne permet de réordonner qu'au sein d'un même conteneur flex, impossible de faire "descendre" un élément dans la colonne gauche d'un flex-row parent depuis l'extérieur. | Réutiliser `order` CSS seul (rejeté -- ne peut pas déplacer un élément entre deux conteneurs flex distincts) ; CSS Grid avec `grid-template-areas` par breakpoint (rejeté -- complexité disproportionnée pour 2 boutons, `AlertDialogTrigger` imbriqué deux fois aurait dupliqué l'état d'ouverture) | actif  |
