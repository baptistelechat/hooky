# LRN-126 — Page autonome en IIFE : exposer ses fonctions dans la copie locale

| Pattern observé                                                                                                                                                                                                                                                                                                                                               | Contexte                                                                                                                                                       | Application future                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Quand le script d'une page autonome est enveloppé dans une IIFE, ses fonctions sont invisibles depuis `javascript_tool`. Dans la copie locale servie en `localhost`, injecter une ligne juste avant la fin de l'IIFE (`window.__x = { fn1, fn2, state }`) permet d'appeler le générateur directement, sans simuler de clics ni intercepter le presse-papiers. | Export de 7 planches Dots Lab : `makeSheet` et `readToken` étaient dans une IIFE. Une boucle sur les liens a produit et posté les 7 fichiers en un seul appel. | Valider ce raccourci avec un témoin : régénérer un export déjà présent dans le repo et le comparer octet par octet (ici `round.svg`, identique à un saut de ligne final près). Ne modifier que la copie locale, jamais la logique du générateur. |
