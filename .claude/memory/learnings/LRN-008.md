# LRN-008 — Le debug overlay doit tracer la session source de l'état affiché, pas la dernière requête

| Pattern observé                                                                                                                                                                                                                                                                                                                             | Contexte                                                                                                                        | Application future                                                                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le payload émis (`lastEvent`/`toolName`) reflétait systématiquement l'event de la requête HTTP en cours de traitement, même quand l'animation affichée (agrégat multi-session) venait d'une AUTRE session plus prioritaire → overlay debug affichant des combinaisons en apparence contradictoires (ex. `animation: waking` / `hook: Stop`) | Signalé par Baptiste comme une contradiction alors que l'agrégat était en réalité correct — juste le libellé debug qui trompait | Dans tout état agrégé multi-source, stocker l'origine (event/session) de CHAQUE entrée et faire remonter celle du "gagnant" pour l'affichage debug, jamais la dernière entrée traitée globalement |
