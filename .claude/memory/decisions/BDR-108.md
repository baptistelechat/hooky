# BDR-108 — Dots Lab livrés sur autorisation publique informelle

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Pourquoi                                                                                                                                                                                                                                                                                                                                                                                                                                 | Alternatives considérées                                                                                                                                                                                                                                                              | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Les 12 planches Dots Lab sont livrées dans le repo avec attribution, sur la base des réponses publiques de l'auteur (Guillaume, @guillaume_rygn) sous son tweet de lancement (`x.com/guillaume_rygn/status/2105554685520146912`, 1er octobre 2026) : « yes you can ! i'm gonna open source it yes », « Sure, go for it! It's free to use », « Of course ! » à une question sur l'intégration dans un projet open source. Seuls les exports sont repris, pas le code du générateur. `src/components/dots/README.md` cite l'auteur, le tweet, les réponses et le lien d'origine de chaque planche, et précise que l'AGPL du repo ne couvre pas ces planches. | Le site ne porte aucune licence (vérifié dans tout le source de la page) : sans les captures fournies par Baptiste, la redistribution sous AGPL était une zone grise. Les réponses de l'auteur couvrent explicitement le cas d'un projet open source. Le risque résiduel (permission informelle, muette sur la modification et la revente par des tiers) est jugé faible pour un projet perso, et retirer quelques SVG resterait simple. | Attendre la publication du code et de sa licence (écarté par Baptiste : inutile pour de simples exports). Ne livrer aucun personnage et laisser l'utilisateur importer les siens (reste prévu en complément). Demander un accord spécifique AGPL sous le tweet (conseillé, non fait). | actif  |
