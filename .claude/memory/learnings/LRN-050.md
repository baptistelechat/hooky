# LRN-050 — `position: relative` imposé via sélecteur CSS commun écrase le `position: absolute` déjà posé

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                                                                                                                                                                                   | Application future                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Une règle CSS commune (`[data-debug] [data-zone] { position: relative; ... }`) appliquée à plusieurs éléments hétérogènes a écrasé le `position: absolute` déjà posé intentionnellement sur certains d'entre eux (badge d'icône, bulle de notification), les faisant apparaître au mauvais endroit — alors que le reste de la règle (contour, étiquette) fonctionnait normalement. | Ajout d'une visualisation de zones en mode debug (fenêtre "main" de Hooky, cf. [BDR-042](../decisions/BDR-042.md)) : le `position: relative` avait été ajouté par réflexe comme "prérequis" pour positionner un pseudo-élément `::before`, sans vérifier qu'il n'était même pas nécessaire (tout élément déjà `absolute`/`relative` établit déjà un contexte de positionnement suffisant). | Avant d'ajouter une propriété "utilitaire" (position, display...) à un sélecteur ciblant plusieurs éléments existants, vérifier qu'aucun des éléments visés n'a déjà une valeur différente pour cette même propriété posée intentionnellement — sinon l'écraser silencieusement. Se demander d'abord si la propriété est réellement nécessaire plutôt que de l'ajouter par réflexe. |
