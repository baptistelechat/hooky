# BDR-003 — Eye tracking souris retiré, avatar simplement centré

**Décision** : Retirer tout le code d'eye tracking (event `hooky-cursor`, `cursor_position()`)

**Pourquoi** : Le moteur Cubee/Strobi n'expose aucune API pour piloter le regard depuis l'extérieur (yeux procéduraux internes, pas mouse-driven). Le contournement testé (lean du corps entier vers le curseur) jugé pas satisfaisant visuellement

**Alternatives considérées** : Lean du corps entier vers le curseur (testé, rejeté à la demande de Baptiste)

Prévu comme bonus dans `docs/BRIEF.md` initial, retiré en pratique après implémentation et test. Backend et frontend nettoyés intégralement (pas de reste de code). À reconsidérer seulement si le moteur d'animation expose un jour ce type de hook.
