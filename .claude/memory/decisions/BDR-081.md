# BDR-081 — Pets Codex : couleur du badge échantillonnée sur les pixels

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Pourquoi                                                                                                                                                                                                                          | Alternatives considérées                                                                                                                                                                                                                                                                      | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `badgeIconColor` d'un pet Codex vient des pixels de sa spritesheet : `src/lib/spriteColor.ts` dessine la ligne `idle` sur un canvas (24 px par cellule), regroupe les pixels chromatiques (saturation ≥ 0,25, luminosité 0,15–0,9) en 12 plages de teinte de 30°, retient la plage dominante si elle couvre ≥ 3 % des pixels opaques (sinon la couleur RGB la plus fréquente), puis applique `ensureReadableOnWhite`. Calcul asynchrone dans le store `useCodexPets`, une fois par chemin de sheet ; repli gris `#475569` tant que ce n'est pas prêt ou en cas d'échec. Résultat sur `work-blue-cat` : `#57a072`. | Le gris constant posé en session 1 n'avait aucun rapport avec le pet (retour de Baptiste). Le décodage se fait dans le webview (canvas) : décoder du WebP côté Rust demanderait une crate d'image pour un simple échantillonnage. | Constante grise (état initial, écartée). Couleur exacte la plus fréquente par groupes RGB de 4 bits : testée sur les vrais pixels, elle retombait sur le gris car le vert du t-shirt pesait 2 % après éparpillement par l'ombrage ([LRN-092](../learnings/LRN-092.md)). Champ de couleur dans `pet.json` : n'existe pas. | actif  |

## Limites

Validé en Node avec les vrais pixels (aucun navigateur disponible, cf. [BLK-034](../blockers/BLK-034.md)), pas dans l'app : la lecture du canvas sur une image `asset:` (CORS) reste à confirmer par Baptiste.
